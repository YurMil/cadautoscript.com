Мы часто слышим об ИИ, который генерирует картинки или стихи. Но для инженеров-механиков и CAD-конструкторов большие языковые модели (LLM) — это не про творчество, а про интерфейс и автоматизацию.

В этой статье разберем, как использовать LLM (GPT-4, Claude 3.5, Llama 3) для управления CAD-системами и обработки технических данных.

{/* truncate */}

:::tip Ключевая идея

LLM плохо справляются с пространственным мышлением (они не умеют хорошо «представлять» 3D-сборку). Зато они отлично понимают API CAD-систем (SolidWorks, AutoCAD, Fusion 360) и умеют писать скрипты для работы с геометрией.

:::

1. Zero-shot генерация макросов

Главное трение в автоматизации CAD — поиск по документации API. Раньше написание VBA-макроса для SolidWorks или Python-скрипта для Blender означало часы поисков по форумам.

Современные LLM проиндексировали эту документацию. Теперь можно запрашивать функциональность, а не синтаксис.

Практический кейс: пакетный экспорт всех листовых деталей из сборки в DXF.

Пример кода (Python + pyautocad)

Вместо того чтобы писать это с нуля, инженер может мгновенно сгенерировать такую заготовку:

```python
from pyautocad import Autocad, APoint

# Сгенерировано LLM для автоматизации рутинных чертежных задач
def draw_gear_profile(teeth, module):
    acad = Autocad(create_if_not_exists=True)
    radius = (teeth * module) / 2
    center = APoint(0, 0)
    
    # LLM понимает специализированные инженерные библиотеки
    acad.model.AddCircle(center, radius)
    print(f"Gear profile created: m{module} z{teeth}")

draw_gear_profile(20, 2)
```

2. Разбор устаревших данных (PDF в JSON)

Инженеры работают с тысячами PDF-даташитов и старых 2D-чертежей. Ручное извлечение параметров (допуски, материал, масса) чревато ошибками.

Мультимодальные LLM умеют «читать» скриншоты технических чертежей и таблиц и структурировать эти данные в JSON для вашей ERP- или PDM-системы.

3. RAG по стандартам (ISO/ГОСТ/DIN)

Вместо того чтобы листать 500-страничный PDF в поисках момента затяжки болта M12 класса прочности 8.8, можно построить RAG-систему (Retrieval-Augmented Generation).

Ввод: «Момент затяжки для M12 8.8»

Система: находит нужную страницу в загруженном PDF стандарта ISO.

Вывод: «81 Нм (Источник: ISO 898-1, таблица 4)»

Итоги

Не просите ИИ спроектировать деталь. Просите ИИ написать код, который автоматизирует скучные этапы проектирования. Так роль инженера смещается от «оператора» к «архитектору автоматизации».
