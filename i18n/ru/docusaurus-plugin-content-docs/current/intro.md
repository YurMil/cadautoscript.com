# Обзор CAD AutoScript

CAD AutoScript — это ориентированный на документацию центр для макросов SolidWorks, расчетных инструментов для производства и инструментов контроля качества. Этот сайт построен на **Docusaurus + MDX**, поэтому каждая утилита задокументирована прямо рядом с ее интерактивным React-компонентом.

## Что здесь находится

- **Макросы SolidWorks**, охватывающие экспорт спецификаций (BOM), проверку основных надписей и помощники по конфигурации.
- **Веб-калькуляторы**, которые работают полностью в Chromium (Pipe Cutter, Shell Rolling, QR-теги и многое другое).
- **Генераторы QA** для парсинга PDF, отслеживания серийных номеров и автоматизации отчетов.
- **Заметки о релизах и рецепты**, чтобы инженеры в цеху знали, как и когда использовать каждый инструмент.

:::tip Только Chromium
Все утилиты поставляются как статические ресурсы и ожидают браузер на базе Chromium (Chrome, Edge, Arc и т. д.) с включенными WebGL 2 и WebAssembly.
:::

## Быстрый старт для разработчиков

1. **Установка зависимостей**
   ```bash
   npm install
   ```
2. **Локальный запуск документации**
   ```bash
   npm start
   ```
3. **Редактирование контента**
   - Страницы Markdown находятся в `docs/`
   - Компоненты React находятся в `src/`
   - Автономные пакеты утилит находятся в `static/utility-apps/`
   - Общие ресурсы оболочки утилит находятся в `static/utilities/`

Docusaurus мгновенно перезагружает изменения. Когда вы будете готовы к публикации, запустите `npm run build` и разверните содержимое `build/` на GitHub Pages.

## Встраивание живых утилит

MDX позволяет нам импортировать React-компоненты или утилиты типа iframe непосредственно на страницы документации. См. [Embedding calculators](utilities/embed-calculators.md) для ознакомления с тем, как оборачивать приложения из `/utilities/*` или создавать специальные виджеты React.
