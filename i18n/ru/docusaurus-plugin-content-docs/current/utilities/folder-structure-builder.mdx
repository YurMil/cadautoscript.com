## Что она делает
Создавайте структуру папок проекта, импортируйте существующие JSON или ZIP и экспортируйте скрипты bash или PowerShell, которые воссоздают эту структуру. Скачайте ZIP или JSON пресет, чтобы коллеги могли создать ту же структуру без ручного ввода.

## Когда использовать (и когда не использовать)
**Используйте, когда:**
- Вы стандартизируете структуру проекта для своей команды.
- Вам нужен быстрый ZIP-архив структуры для начала работы без использования CLI.
- Вы хотите поделиться пресетом папок между разными машинами или командами.

**Избегайте, когда:**
- Вам нужно настроить серверы или сложные права доступа; утилита фокусируется только на структуре папок.
- Ваше дерево содержит тысячи узлов; в этом случае лучше использовать шаблоны в коде.

## Входные и выходные данные
### Входные данные
| Данные | Описание |
| --- | --- |
| Узлы папок и файлов | Добавляйте папки или файлы в реальном времени для проектирования дерева. |
| Импорт JSON или ZIP | Загрузите существующую структуру для изменения или повторного использования. |
| Опции скрипта | Выберите экспорт в bash или PowerShell в зависимости от вашей среды. |
| Метаданные пресета | Дополнительные метки или примечания для структуры. |

### Выходные данные
| Данные | Формат | Примечания |
| --- | --- | --- |
| Скрипт Bash | .sh | Скрипт для воссоздания дерева в Unix-подобных системах. |
| Скрипт PowerShell | .ps1 | Скрипт для воссоздания дерева в Windows. |
| ZIP-архив структуры | ZIP | Пустые папки/файлы, упакованные в архив для быстрой передачи. |
| JSON пресет | JSON | Многоразовый пресет для последующего импорта. |

## Как использовать
1. Создайте новое дерево или импортируйте существующий JSON/ZIP.
2. Добавляйте папки и файлы, пока структура не будет соответствовать шаблону вашего проекта.
3. Выберите экспорт в bash или PowerShell (или оба).
4. Скачайте скрипт, ZIP или JSON пресет.
5. Запустите скрипт в безопасной директории, чтобы построить структуру.

**Пример:** Создайте структуру с папками src/, docs/, tests/ и файлом README.md; экспортируйте PowerShell скрипт и ZIP для команды.
- Ожидаемый результат: Предоставляется скрипт .ps1, скрипт shell, ZIP-архив структуры и JSON пресет, представляющие одно и то же дерево.

## Точность и проверка
- Скрипты создают директории при их запуске; проверяйте пути перед выполнением.
- Специальные символы могут требовать кавычек в разных оболочках; настройте их, если ваша среда строгая.
- Большие деревья ограничены памятью браузера при экспорте в ZIP.
- Вся генерация происходит локально; храните пресеты под контролем версий, если это необходимо.

## FAQ
- **Изменяет ли утилита мой диск автоматически?** Нет. Она только создает скрипты или ZIP-архивы; вы запускаете их там, где хотите создать дерево.
- **Могу ли я делиться пресетами?** Да. Экспортируйте JSON и отправьте его своей команде.
- **Работает ли она офлайн?** Да. Все происходит в браузере.
- **Как обрабатываются специальные символы?** Скрипты экранируют обычные символы, но проверяйте пути при использовании специфических имен.
- **Могу ли я импортировать существующее дерево?** Да. Импортируйте из JSON или ZIP-архива.
