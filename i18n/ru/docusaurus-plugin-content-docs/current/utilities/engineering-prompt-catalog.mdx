# Engineering Prompt Catalog

Просматривайте курируемую библиотеку шаблонов промптов для КИПиА, механического проектирования и закупок.

<a className="button button--primary" href="/utilities/engineering-prompt-catalog/" data-nobrokenlinkcheck>Открыть утилиту</a>

## Что делает
- Группирует промпты по дисциплинам и подкатегориям для быстрой фильтрации.
- Выделяет плейсхолдеры, чтобы вы могли заменить их реальными значениями за секунды.
- Копирует промпты в буфер обмена или скачивает их в формате Markdown.
- Использует наглядную таблицу для быстрого перехода между основными категориями.

## Когда использовать (и когда нет)
**Используйте, когда:**
- Вам нужна быстрая и последовательная структура промпта для технических задач.
- Вы хотите стандартизировать способ запроса спецификаций, расчетов или RFQ в вашей команде.
- Вам нужен быстрый шаблон промпта без открытия библиотеки документов.

**Избегайте, когда:**
- Работа требует конфиденциальных данных, которые не должны помещаться в инструменты ИИ.
- Вам нужен полный контекст проекта или извлечение данных из чертежей.

## Входные и выходные данные
### Входные данные
| Вход | Описание |
| --- | --- |
| Фильтр категорий | Выберите КИПиА, Механика или Закупки, чтобы сузить результаты. |
| Фильтр подкатегорий | Перейдите в такие области, как Расчет клапанов, SolidWorks или RFQ. |
| Поиск | Найдите промпты по ключевым словам в цели или тексте промпта. |

### Выходные данные
| Выход | Формат | Примечания |
| --- | --- | --- |
| Карточки промптов | На экране | Готовые к копированию шаблоны с плейсхолдерами. |
| Копия в буфер | Простой текст | Копирование полного промпта в один клик. |
| Файл Markdown | .md | Имя скачанного файла соответствует названию промпта. |

## Как использовать
1. Откройте утилиту и выберите дисциплину на боковой панели.
2. Выберите подкатегорию или введите ключевое слово в строке поиска.
3. Нажмите **Copy**, чтобы использовать промпт, или **Save MD**, чтобы скачать его.
4. Замените плейсхолдеры в скобках значениями, специфичными для вашего проекта.

**Пример:** Отфильтруйте **КИПиА → Расчет клапанов**, скопируйте промпт для расчета Cv, замените `[P1]`, `[P2]` и `[Q]`, затем вставьте в ваш инструмент ИИ.

## Точность и проверка
- Промпты являются только шаблонами. Всегда проверяйте результаты на соответствие вашим стандартам и расчетам.
- Удаляйте конфиденциальные данные перед вставкой промптов в любые внешние системы.
- Соблюдайте единство систем единиц при заполнении плейсхолдеров.

## FAQ
- **Работает ли он офлайн?** Да. Библиотека промптов встроена и работает полностью в браузере.
- **Можно ли добавить свои промпты?** Пока нет. Этот каталог представляет собой фиксированный стартовый набор.
- **Будут ли мои данные сохраняться или загружаться?** Нет. Копирование и скачивание происходят локально.
- **Почему плейсхолдеры в скобках?** Их легко сканировать и заменять перед использованием.
