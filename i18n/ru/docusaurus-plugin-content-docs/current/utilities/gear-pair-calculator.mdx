## Ключевые возможности

- **Решатель геометрии**: Обрабатывает стандартные и корригированные ($x_1, x_2$) внешние прямозубые колеса. Вычисляет рабочий угол зацепления $\alpha_w$ и межосевое расстояние $a_w$.
- **Проверки качества зацепления**: Мгновенная обратная связь по коэффициенту перекрытия, предупреждениям о подрезании, проверкам тела колеса/отверстия и интерференции зубьев.
- **Поиск передаточного отношения**: Предлагает подходящие комбинации чисел зубьев и модулей для достижения требуемого передаточного отношения и межосевого расстояния.
- **2D- и 3D-превью зацепления**: Динамические превью с анимацией, скорость которой соответствует заданным оборотам (RPM), позволяют визуально оценить качество зацепления.
- **Экспорт в CAD**: Экспорт замкнутых 2D-полилиний в DXF (со слоями для профилей, делительных/основных/наружных/впадинных окружностей) и 3D-тел в STEP через браузерный Web Worker (OpenCascade.js).
- **PDF-отчеты о расчете**: Формирует готовую к печати документацию, включая вывод формул, предупреждения, допущения и таблицы размеров.

## Поддерживаемые расчеты

| Область | Параметры | Стандарты и результаты |
|---|---|---|
| **Геометрия** | Модуль, число зубьев, угол зацепления, смещения, боковой зазор, ширина венца | Делительный, основной, наружный диаметры, диаметр впадин, рабочее межосевое расстояние |
| **Качество зацепления** | Коэффициент перекрытия, границы подрезания, ограничения перекрытия | Торцовый коэффициент перекрытия ($\epsilon_\alpha$), целостность профиля |
| **Нагрузки и силы** | Крутящий момент, частота вращения (RPM), КПД, коэффициент режима работы | Окружная сила ($F_t$), радиальная ($F_r$), нормальная ($F_n$), окружная скорость ($v$) |
| **Запас по изгибу** | Допускаемые напряжения материала, допущения по режиму работы | Оценка изгибного напряжения ($\sigma_b$) и коэффициента запаса по методу Льюиса |

## Важное примечание

Расчеты, оценки напряжений и CAD-файлы, предоставляемые этой утилитой, предназначены для предварительной инженерной оценки, прототипирования и CAD-макетов. Проверки на изгиб используют упрощенную формулу Льюиса и не являются полноценным расчетом по ISO 6336 или AGMA. Всегда проверяйте окончательную конструкцию передачи по сертифицированным стандартам с помощью специализированного ПО перед запуском в производство.

## Основной рабочий процесс

1. **Выберите режим подбора**: Выберите **Existing Gear Pair Check** для проверки конкретных размеров или **Ratio-driven Sizing** для поиска вариантов.
2. **Настройте входные параметры**: Задайте базовые параметры передачи: модуль, угол зацепления, числа зубьев, ширину венца и смещения профиля.
3. **Проверьте предупреждения и валидацию**: Убедитесь, что индикатор коэффициента перекрытия зеленый ($> 1.4$) и что не отмечены ошибки подрезания или интерференции.
4. **Изучите визуальное зацепление**: Проверьте вкладки 2D-эскиза зацепления и 3D-превью. Включите анимацию, чтобы проверить направление зацепления колес.
5. **Скачайте CAD-файлы и отчеты**: Экспортируйте файлы DXF для вырезки профилей, файлы STEP для CAD-сборок и PDF-отчет для проектной документации.
