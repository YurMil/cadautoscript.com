## Что она делает
Загружайте PDF-файлы, фильтруйте найденные числа с помощью регулярных выражений (regex) или правил длины и экспортируйте чистый список совпадений. Парсинг происходит в браузере с помощью WASM, поэтому серийные номера QA, идентификаторы BOM и номера инспекций никогда не покидают ваше устройство.

## Когда использовать (и когда не использовать)
**Используйте, когда:**
- Вам нужно извлечь серийные номера или идентификаторы из производственных PDF для контроля качества (QA) или прослеживаемости.
- Вы хотите предварительно заполнить таблицы идентификаторами инспекций без ручного ввода.
- Вы предпочитаете автономный рабочий процесс без загрузок или очередей.

**Избегайте, когда:**
- Ваши PDF — это отсканированные изображения, требующие OCR, а не парсинга текста.
- Вам нужен полнотекстовый поиск сразу по тысячам страниц.

## Входные и выходные данные
### Входные данные
| Вход | Описание |
| --- | --- |
| PDF-файлы | Один или несколько PDF, перетащенных в браузер. |
| Правила Regex или фильтры | Включайте или исключайте шаблоны, чтобы изолировать нужные числа. |
| Мин/макс длина | Необязательные ограничения, чтобы избежать шума, такого как номера страниц. |
| Опции экспорта | Выберите экспорт в CSV или копирование в буфер обмена. |

### Выходные данные
| Выход | Формат | Примечания |
| --- | --- | --- |
| Выделенные совпадения | На экране | Визуальное наложение найденных чисел для быстрой проверки QA. |
| Экспорт в CSV | CSV | Список извлеченных чисел по каждому файлу, готовый для таблиц. |
| Копирование в буфер | Текст | Быстрое копирование совпадений без скачивания файла. |

## Как использовать
1. Перетащите PDF-файлы в утилиту.
2. Добавьте фильтры по регулярному выражению (regex) или длине для выбора нужных ID.
3. Проверьте выделенные совпадения на экране.
4. Экспортируйте результаты в CSV или скопируйте их в буфер обмена.
5. Очистите сессию по окончании; ничего не загружается в интернет.

**Пример данных:** Загрузите отчет об инспекции, содержащий ID типа SN-2025-104; используйте regex вида SN-\\d{4}-\\d{3} и экспортируйте CSV.
- Ожидаемый результат: Создается CSV со списком совпадений в стиле SN-2025-104 и визуальное выделение на экране для подтверждения.

## Точность и проверка
- Работает с текстовыми PDF; отсканированные изображения требуют OCR сторонними средствами.
- Фильтры чувствительны к регистру только если вы это укажете; дважды проверьте шаблоны перед экспортом.
- Сетевые вызовы не выполняются, поэтому сохраняйте локальную копию результатов для аудита.
- Выборочно проверьте несколько строк по PDF, чтобы убедиться, что regex не отфильтровал лишнего.

## FAQ
- **Распознает ли он текст на отсканированных PDF (OCR)?** Нет. Он читает существующий текст; если PDF является изображением, сначала используйте OCR.
- **Могу ли я обработать несколько файлов?** Да. Загрузите пакет PDF и экспортируйте комбинированные результаты.
- **Загружаются ли данные на сервер?** Нет. Парсинг происходит локально в вашем браузере.
- **Могу ли я настроить регулярное выражение (regex)?** Да. Поддерживается стандартный синтаксис JavaScript regex.
- **Могу ли я сохранить выделение (highlights)?** Экспортируйте CSV и сохраните копию PDF; выделение предназначено только для проверки на экране.
