## Что оно делает

Перетащите лог-файл, экспортированный из цифрового калибратора давления **WIKA CPG1500**, и мгновенно получите:

- **Карточка идентификации устройства** — серийный номер, модель, версия прошивки, даты калибровки и метаданные оператора, извлеченные из заголовка файла.
- **Сетка данных измерений** — таблица всех показаний давления/температуры с отметками времени, доступная для поиска и сортировки.
- **График давления** — интерактивный линейный график записанной кривой давления во времени.
- **Готовый к печати отчет КК** — многостраничный макет, оптимизированный для печати (портретная ориентация A4 для таблиц, альбомная A4 для графиков), который можно отправить прямо на принтер или сохранить в PDF.

Всё работает на стороне клиента с использованием React и Material UI. Данные не покидают браузер.

## Когда использовать (и когда нет)

**Используйте, когда:**
- Вам нужно просмотреть логи калибровки WIKA CPG1500 на любой машине с браузером.
- Вы хотите быстро визуально проверить кривую давления перед оформлением сертификата.
- Вам нужно распечатать или сохранить в PDF отформатированный отчет КК для приложения к сопроводительной документации.
- Вы хотите искать или сортировать результаты измерений без импорта необработанного файла в Excel.

**Избегайте, когда:**
- Ваши лог-файлы получены от другой модели калибратора (парсер специфичен для CPG1500).
- Вам нужна пакетная обработка десятков логов одновременно (загружайте по одному файлу за раз).

## Входы и выходы

### Входы
| Вход | Описание |
| :--- | :--- |
| **Лог-файл** | Файл `.log` или `.txt`, экспортированный из калибратора WIKA CPG1500. |

### Выходы
| Выход | Формат | Примечания |
| :--- | :--- | :--- |
| **Идентификация устройства** | Карточка на экране | Серийный номер, модель, прошивка, даты калибровки, оператор. |
| **Таблица измерений** | Сетка на экране | Показания давления и температуры с отметками времени и поиском. |
| **График давления** | Интерактивный график | Линейный график зависимости давления от времени. |
| **Отчет КК** | Печать / PDF | Многостраничный отчет, оптимизированный для A4, через диалог печати браузера. |

## Как использовать

1. **Откройте утилиту** и кликните по области загрузки или перетащите лог-файл CPG1500.
2. **Проверьте карточку идентификации устройства** — подтвердите правильность серийного номера, модели и дат калибровки.
3. **Просмотрите сетку измерений** — используйте поле поиска для фильтрации строк или кликайте по заголовкам столбцов для сортировки.
4. **Изучите график давления** — наводите на точки данных для получения точных значений; используйте зум или панорамирование, если доступно.
5. **Распечатайте отчет** — нажмите кнопку печати в браузере (`Ctrl+P` / `Cmd+P`). Макет автоматически переключится на отчет, оптимизированный для A4, с разрывами страниц для карточки идентификации, таблицы данных и графика.

### Пример рабочего процесса
Загрузите лог-файл недавнего теста давления → убедитесь, что серийный номер устройства совпадает с сертификатом калибровки → проверьте кривую давления на наличие аномалий → распечатайте отформатированный отчет и прикрепите его к сопроводительному листу.

## Макет печати отчета

Стиль печати создает чистый многостраничный отчет КК:

| Страница | Содержание | Ориентация |
| :--- | :--- | :--- |
| 1 | Идентификация устройства + краткая сводка измерений | Портретная (A4) |
| 2+ | Полная таблица данных измерений | Портретная (A4) |
| Страница графика | График давления с легендой | Альбомная (A4) |

:::tip
Используйте "Сохранить как PDF" в диалоговом окне печати вашего браузера, чтобы архивировать отчет в цифровом виде вместе с вашими калибровочными сертификатами.
:::

## Точность и конфиденциальность

- **Только извлеченные данные** — утилита не изменяет исходный лог-файл; она считывает и отображает значения как есть.
- **Никаких загрузок** — весь парсинг происходит в браузере с помощью клиентского JavaScript. Никакие данные не передаются на сервер.
- **Только в рамках сессии** — закройте вкладку, и все обработанные данные исчезнут. Сохраните или распечатайте отчет перед закрытием.
- **Сверяйте с источником** — всегда перепроверяйте критические значения (серийный номер, тестовое давление) с оригинальным лог-файлом и калибровочным сертификатом.

## FAQ

- **Какие форматы лог-файлов поддерживаются?** Лог-файлы, экспортированные из цифровых калибраторов давления WIKA CPG1500 (`.log` / `.txt`).
- **Загружаются ли мои данные на сервер?** Нет. Всё остается в браузере.
- **Могу ли я распечатать или сохранить отчет?** Да. Используйте `Ctrl+P` / `Cmd+P` для печати или сохранения в PDF. Макет оптимизирован для бумаги формата A4.
- **Работает ли это офлайн?** Да, после загрузки страницы подключение к интернету не требуется.
- **Можно ли анализировать несколько файлов одновременно?** Загружайте по одному файлу за раз; обновите или очистите страницу для анализа другого лога.
- **Что если мой лог-файл не распознается?** Парсер специфичен для формата CPG1500. Файлы с других приборов могут не распознаваться. Откройте задачу на GitHub, если считаете, что ваш файл CPG1500 должен работать, но не работает.
