# React Table Editor

Открывайте файлы CSV или XLSX, редактируйте данные прямо в таблице и экспортируйте чистые таблицы локально в браузере.

<a className="button button--primary" href="/utilities/react-table-editor/" data-nobrokenlinkcheck>Открыть утилиту</a>

## Что это делает
- Импортирует табличные данные из файлов CSV и XLSX.
- Позволяет редактировать ячейки на месте и настраивать строки/столбцы.
- Поддерживает клиентский экспорт обратно в CSV или XLSX.
- Сохраняет данные локально без загрузки на сервер.

## Когда использовать (и когда нет)
**Используйте, когда:**
- Вам нужна быстрая очистка таблиц BOM, QA или производственных спецификаций.
- Вы хотите нормализовать электронные таблицы перед передачей в системы CAD/ERP.
- Вам нужно редактирование только в браузере без настольного офисного ПО.

**Избегайте, когда:**
- Вам нужны сложные формулы и сводные таблицы.
- Вам нужна многопользовательская совместная работа в реальном времени.

## Входные и выходные данные
### Входные данные
| Вход | Описание |
| --- | --- |
| Файл CSV/XLSX | Загрузите одну таблицу для интерактивного редактирования. |
| Ручное редактирование | Обновление ячеек, заголовков столбцов и значений строк. |

### Выходные данные
| Выход | Формат | Примечания |
| --- | --- | --- |
| Отредактированная таблица | На экране | Живой предпросмотр сетки с мгновенным обновлением. |
| Экспортированный файл | CSV/XLSX | Сохранение очищенного набора данных для дальнейшего использования. |

## Как использовать
1. Импортируйте файл CSV или XLSX.
2. Просмотрите таблицу и отредактируйте ячейки по мере необходимости.
3. Добавьте/удалите строки или столбцы, если ваш рабочий процесс требует изменения структуры.
4. Экспортируйте финальную таблицу в CSV или XLSX.

## Точность и проверка
- Проверьте единицы измерения, разделители и названия заголовков перед экспортом.
- Повторно откройте экспортированный файл в целевой программе, чтобы подтвердить совместимость.
- Данные остаются в сессии вашего браузера, пока вы их не экспортируете.

## FAQ
- **Загружается ли мой файл на сервер?** Нет, обработка выполняется локально в вашем браузере.
- **Какие форматы поддерживаются?** CSV и XLSX.
- **Можно ли редактировать формулы?** Утилита оптимизирована для редактирования значений, а не для сложных формул электронных таблиц.
- **Можно ли использовать офлайн?** Если ресурсы кэшированы и доступны локально в браузере, то да.
