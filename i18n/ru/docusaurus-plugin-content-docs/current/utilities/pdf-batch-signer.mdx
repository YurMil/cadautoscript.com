## Что она делает
Создавайте многоразовую подпись (рисуя, печатая или загружая скан), размещайте её в режиме предварительного просмотра и применяйте ко всем страницам вашего пакета PDF. Опциональный анализ Gemini может считывать основные надписи (штампы), если вы предоставите собственный API key; в противном случае всё остается локально.

## Когда использовать (и когда не использовать)
**Используйте, когда:**
- Вам нужно поставить штамп на несколько чертежей или отчетов за один проход без использования облачных сервисов.
- Вы хотите обеспечить единообразное размещение подписи на каждой странице пакета.
- Вам нужен быстрый ZIP-архив подписанных PDF для отправки поставщикам или в отдел контроля качества (QA).

**Избегайте, когда:**
- Вам требуются криптографические подписи или подписи на основе сертификатов.
- Ваши страницы имеют сильно различающиеся размеры, требующие уникального размещения для каждой страницы.

## Входные и выходные данные
### Входные данные
| Вход | Описание |
| --- | --- |
| Пакет PDF | Один или несколько PDF-файлов для нанесения штампа за один раз. |
| Источник подписи | Нарисуйте, напечатайте или загрузите изображение подписи для повторного использования. |
| Размещение и масштаб | Установите положение и размер подписи в режиме предварительного просмотра перед применением. |
| Опциональный Gemini API key | Если вы хотите извлечь данные из основной надписи; в противном случае всё остается оффлайн. |

### Выходные данные
| Выход | Формат | Примечания |
| --- | --- | --- |
| Подписанные PDF | ZIP | Все входные файлы со штампом в одном и том же месте. |
| Предварительный просмотр | На экране | Визуальная проверка нанесенной подписи. |

## Как использовать
1. Загрузите PDF-файлы, которые нужно подписать.
2. Создайте или загрузите подпись, настройте её положение и размер.
3. Опционально добавьте Gemini API key, если хотите извлечь метаданные из основной надписи чертежа.
4. Примените подпись ко всем страницам.
5. Скачайте ZIP-архив подписанных PDF.

**Пример данных:** Загрузите десять PDF-чертежей, нарисуйте подпись, разместите её в 20 мм от правого нижнего угла, оставьте Gemini выключенным и экспортируйте ZIP.
- Ожидаемый результат: Скачивается ZIP-архив, содержащий все чертежи с одинаковым видимым расположением подписи на каждой странице.

## Точность и проверка
- Наносит графический штамп, а не цифровой сертификат; проверьте допустимость использования для регламентированных документов.
- Смешанные форматы страниц могут потребовать быстрой визуальной проверки после подписания.
- Опциональное извлечение данных Gemini использует ваш ключ на стороне клиента; оставьте поле пустым, чтобы всё оставалось оффлайн.
- Сохраняйте оригиналы, если вам нужен аудит; инструмент перезаписывает только скачиваемые копии.

## FAQ
- **Является ли это цифровым сертификатом?** Нет. Это графическая подпись, наносимая локально.
- **Будут ли мои файлы куда-то загружаться?** Нет. Процесс подписания выполняется с помощью pdf-lib и JSZip прямо в вашем браузере.
- **Могу ли я обрабатывать страницы разных размеров?** Да, но перед экспортом всего набора проверьте размещение на тестовой странице.
- **Как мне изменить штамп позже?** Загрузите файлы снова, настройте подпись и выполните экспорт повторно.
- **Что насчет меток времени?** Добавьте текст с датой внутрь изображения подписи или запустите процесс заново с обновленной меткой.
