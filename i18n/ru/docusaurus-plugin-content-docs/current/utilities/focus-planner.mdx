## Премиальная продуктивность, локальная приватность
Focus Planner — это не просто очередной список задач; это полноценное рабочее пространство, построенное на философии "Local-First". Ваши данные никогда не покидают браузер, обеспечивая полную приватность и предоставляя мощные инструменты, обычно доступные только в облачных решениях.

### Ключевые возможности
*   **Единая панель управления**: Чистый интерфейс "Welcome Back", показывающий ваш ежедневный прогресс, заработанные награды и запланированные задачи одним взглядом.
*   **Геймификация успеха**: Сохраняйте мотивацию с помощью встроенной системы наград. Получайте значки за достижение целей по фокусу и выполнение запланированной работы.
*   **Интеграция с календарем**: Планируйте свое время с точностью, используя несколько режимов просмотра (День, Неделя, Месяц, Квартал). Планируйте задачи прямо в календаре.
*   **Встроенные таймеры**: Начинайте отслеживание времени мгновенно прямо из списка задач. Связанные таймеры гарантируют, что каждая минута фокуса будет отнесена к нужному проекту.
*   **Работа в офлайне**: Создано для полной работы в автономном режиме. Ваш прогресс сохраняется локально и остается доступным даже после перезапуска браузера или обновления страницы.

## Обзор рабочего процесса
### 1. Планирование
Определите категории и задачи в рабочем пространстве **Tasks**. Используйте **Calendar**, чтобы заблокировать время для глубокой работы.
### 2. Фокус
Запустите **Dashboard**, чтобы увидеть основные приоритеты на день. Используйте встроенные кнопки "Play" на карточках задач, чтобы начать сессии фокуса.
### 3. Обзор
Анализируйте свою эффективность во вкладке **Analytics**. Отслеживайте распределение фокуса по категориям и наблюдайте, как растет ваша коллекция наград.
### 4. Управление
Используйте **Settings** для настройки внешнего вида, управления резервными копиями или экспорта данных для внешнего использования.

## Входные и выходные данные
| Функция | Входные данные | Результат / Формат |
| :--- | :--- | :--- |
| **Управление задачами** | Названия, Категории, Приоритеты | Визуальный список задач с отслеживанием статуса |
| **Планирование** | Размещение в календаре, Дедлайны | Интерактивные режимы День/Неделя/Месяц |

## Когда использовать Focus Planner
*   **Сессии глубокой работы:** Когда вам нужна среда без отвлекающих факторов для отслеживания задач с высокой концентрацией.
*   **Планирование с приоритетом приватности:** Когда вам нужен профессиональный инструмент без необходимости создания аккаунта или облачной синхронизации.
*   **Консолидированный рабочий процесс:** Когда вы хотите, чтобы задачи, календарь и таймеры были в едином локальном интерфейсе.

## Точность и приватность
*   **Никакой облачной синхронизации:** Данные не отправляются на внешние серверы. Вся информация остается в IndexedDB вашего браузера.
*   **Восстановление таймера:** Приложение разработано для автоматического возобновления активных таймеров после перезагрузки страницы.
*   **Портативность данных:** Вы полностью контролируете свои данные. Экспортируйте все рабочее пространство в формате JSON или отдельные отчеты в CSV в любое время.

## FAQ
*   **Безопасны ли мои данные?** Да, они хранятся локально в вашем браузере. Однако очистка данных сайта в браузере удалит ваши задачи, если вы не экспортировали резервную копию.
*   **Нужен ли мне аккаунт?** Нет. Просто откройте утилиту и начните планирование.
*   **Могу ли я синхронизировать данные между устройствами?** Напрямую — нет. Используйте функцию экспорта/импорта JSON в настройках (Settings), чтобы перенести рабочее пространство на другую машину.
