## Что делает
Загрузите группу файлов, просмотрите новые имена с помощью поиска/замены (включая регулярные выражения), добавьте префиксы, суффиксы или нумерацию и скачайте переименованный набор в виде ZIP-архива. Все работает в браузере, поэтому ваши файлы остаются локальными.

## Когда использовать (и когда нет)
**Используйте, когда:**
- Вам нужно привести в порядок названия чертежей или добавить номера заданий перед отправкой пакета документов.
- Вы хотите массово применить нумерацию или префиксы без написания скриптов.
- Вы предпочитаете быстрое офлайн-переименование с получением готового ZIP-архива.

**Избегайте, когда:**
- Вам нужно переименовать тысячи файлов на диске; в этом случае лучше использовать CLI-скрипт.
- Вам необходимо сохранить иерархию вложенных папок; объединение файлов в один уровень может быть нежелательным.

## Входные и выходные данные
### Входные данные
| Вход | Описание |
| --- | --- |
| Файлы для переименования | Перетащите файлы, которые хотите обработать. |
| Правила поиска/замены | Используйте обычные строки или регулярные выражения для трансформации имен. |
| Префикс/суффикс | Добавьте номера заказов, ревизии или другие теги. |
| Нумерация | Установите начало, шаг и дополнение нулями для порядковых номеров. |
| Регистр | Опциональное преобразование в верхний/нижний регистр или kebab-case. |

### Выходные данные
| Выход | Формат | Примечания |
| --- | --- | --- |
| Таблица предварительного просмотра | На экране | Сравнение старых и новых имен перед экспортом. |
| Переименованные файлы | ZIP | Скачиваемый архив с обновленными именами файлов. |

## Как использовать
1. Перетащите файлы для переименования.
2. Примените правила поиска/замены, префиксы, суффиксы или нумерацию.
3. Проверьте таблицу предпросмотра, чтобы убедиться в отсутствии конфликтов имен.
4. Скачайте ZIP-архив с переименованными файлами.
5. Отправьте или заархивируйте переименованный пакет.

**Пример:** Загрузите `P-001.pdf`, `P-002.pdf`; найдите 'P-' и замените на 'FAB-', добавьте префикс `2025_`, начните нумерацию с 10.
- Ожидаемый результат: Скачивается ZIP-архив с файлами `2025_FAB-10.pdf` и `2025_FAB-11.pdf`.

## Точность и проверка
- Переименование происходит в браузере; сохраняйте оригиналы, пока не проверите ZIP.
- Регулярные выражения — мощный инструмент, сначала протестируйте их на небольшом наборе файлов.
- Конфликты имен обрабатываются в предпросмотре; разрешите их перед экспортом.
- Большие пакеты ограничены памятью браузера; при необходимости разделяйте их.

## FAQ
- **Работают ли регулярные выражения (regex)?** Да. Используйте стандартные регулярные выражения JavaScript для сложного переименования.
- **Сохраняется ли структура папок?** Файлы объединяются в один ZIP-архив с новыми именами без сохранения иерархии папок.
- **Загружаются ли данные на сервер?** Нет. Все процессы выполняются локально в вашем браузере.
- **Сколько файлов можно переименовать за раз?** Это зависит от памяти браузера; очень большие наборы лучше разделять на части.
- **Что происходит с содержимым файлов?** Содержимое остается неизменным; обновляются только имена файлов.
