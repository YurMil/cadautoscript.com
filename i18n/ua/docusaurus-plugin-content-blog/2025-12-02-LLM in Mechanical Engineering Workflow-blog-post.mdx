Ми часто чуємо про ШІ, який генерує картинки чи вірші. Але для інженерів-механіків і CAD-конструкторів великі мовні моделі (LLM) — це не про творчість, а про інтерфейс та автоматизацію.

У цій статті розглянемо, як використати LLM (GPT-4, Claude 3.5, Llama 3) для керування CAD-системами та обробки технічних даних.

:::tip Ключова ідея

LLM погано впораються з просторовим мисленням (вони не вміють добре «уявляти» 3D-складання). Зате вони чудово розуміють API CAD-систем (SolidWorks, AutoCAD, Fusion 360) і вміють писати скрипти для роботи з геометрією.

:::

1. Zero-shot генерація макросів

Головне тертя в автоматизації CAD — пошук по документації API. Раніше написання VBA-макроса для SolidWorks або Python-скрипта для Blender означало години пошуків на форумах.

Сучасні LLM проіндексували цю документацію. Тепер можна запитувати функціональність, а не синтаксис.

Практичний кейс: пакетний експорт усіх листових деталей зі складання в DXF.

Приклад коду (Python + pyautocad)

Замість того щоб писати це з нуля, інженер може миттєво згенерувати таку заготовку:

```python
from pyautocad import Autocad, APoint

# Згенеровано LLM для автоматизації рутинних креслярських задач
def draw_gear_profile(teeth, module):
    acad = Autocad(create_if_not_exists=True)
    radius = (teeth * module) / 2
    center = APoint(0, 0)
    
    # LLM розуміє спеціалізовані інженерні бібліотеки
    acad.model.AddCircle(center, radius)
    print(f"Gear profile created: m{module} z{teeth}")

draw_gear_profile(20, 2)
```

2. Розбір застарілих даних (PDF у JSON)

Інженери працюють з тисячами PDF-даташитів і старих 2D-креслень. Ручне вилучення параметрів (допуски, матеріал, маса) загрожує помилками.

Мультимодальні LLM вміють «читати» скриншоти технічних креслень і таблиць та структурувати ці дані в JSON для вашої ERP- або PDM-системи.

3. RAG за стандартами (ISO/ГОСТ/DIN)

Замість того щоб гортати 500-сторінковий PDF у пошуках моменту затягування болта M12 класу міцності 8.8, можна побудувати RAG-систему (Retrieval-Augmented Generation).

Ввід: «Момент затягування для M12 8.8»

Система: знаходить потрібну сторінку в завантаженому PDF стандарту ISO.

Вивід: «81 Нм (Джерело: ISO 898-1, таблиця 4)»
