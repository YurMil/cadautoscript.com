## Що вона робить
Завантажуйте PDF, створені в CAD, автоматично визначайте рядки заголовків та колонок, прибирайте зайві рядки ревізій або футерів та експортуйте CSV-файли для кожного файлу або у вигляді об'єднаного звіту. Все працює на стороні клієнта, тому креслення та витягнуті дані залишаються на вашому пристрої.

## Коли використовувати (і коли не використовувати)
**Використовуйте, коли:**
- Ви хочете витягти BOM таблиці з креслень PDF без ручного передруковування.
- Вам потрібен швидкий експорт у CSV для передачі у відділ закупівель або QA.
- Ви віддаєте перевагу локальному парсингу без завантаження файлів у хмару.

**Уникайте, коли:**
- Ваші PDF — це відскановані зображення, для читання яких потрібне OCR.
- Таблиці мають складні об'єднані клітинки або змінну кількість колонок, що заважає автовизначенню.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Креслення PDF | Векторні PDF-файли з BOM або таблицями специфікацій. |
| Вибір рядка заголовка | Підтвердьте або налаштуйте, який рядок визначає заголовки колонок. |
| Налаштування автовизначення колонок | Керуйте тим, як парсер групує колонки. |
| Фільтри рядків | Пропускайте рядки ревізій або футерів, які не потрібні в CSV. |
| Опція загального звіту (Master report) | Об'єднайте результати в один CSV-файл за потреби. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| CSV для кожного файлу | CSV | По одному CSV-файлу для кожного обробленого PDF. |
| Загальний CSV (Master CSV) | CSV | Опціональний об'єднаний звіт за всіма завантаженими файлами. |
| Таблиця попереднього перегляду | На екрані | Перевірте та підправте дані перед завантаженням. |

## Як використовувати
1. Завантажте один або кілька креслень PDF.
2. Підтвердьте визначений рядок заголовка та за потреби налаштуйте колонки.
3. Приберіть зайві рядки футера або ревізій.
4. Завантажте CSV для кожного файлу або загальний звіт.
5. Архівуйте CSV-файли разом із пакетом документів за завданням.

**Приклад даних:** Завантажте два PDF-файли збірки з BOM таблицями, залиште 2-й рядок як заголовок, приберіть примітки до ревізій та експортуйте як окремі CSV, так і master_report.csv.
- Очікуваний результат: Створюються два окремі CSV-файли плюс об'єднаний майстер-файл із вирівняними колонками.

## Точність та перевірка
- Залежить від можливості виділення тексту; відсканованим PDF спочатку потрібне OCR.
- Об'єднані або нестандартні таблиці можуть вимагати ручного очищення після експорту.
- Перевіряйте попередній перегляд перед завантаженням, щоб переконатися у правильному визначенні рядка заголовка.
- Весь парсинг виконується локально; зберігайте власні резервні копії експортованих CSV.

## FAQ
- **Чи розпізнає він текст на зображеннях (OCR)?** Ні. Він читає тільки векторний текст.
- **Чи можу я обробити відразу багато файлів?** Так. Завантажте пакет файлів та експортуйте дані для кожного файлу окремо або у вигляді загального звіту (master report).
- **Чи завантажуються якісь дані на сервер?** Ні. Все залишається в браузері.
- **Як обробляються об'єднані клітинки?** Парсер вирівнює колонки; за потреби перевірте та відредагуйте дані після експорту.
- **Чи можу я змінити роздільник?** Експорт виконується у форматі CSV; ви можете змінити роздільники пізніше у вашій програмі для роботи з таблицями.
