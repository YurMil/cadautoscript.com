## Що вона робить
Створюйте структуру папок проєкту, імпортуйте існуючі JSON або ZIP та експортуйте скрипти bash або PowerShell, які відтворюють цю структуру. Завантажте ZIP або JSON пресет, щоб колеги могли створити ту саму структуру без ручного введення.

## Коли використовувати (і коли не використовувати)
**Використовуйте, коли:**
- Ви стандартизуєте структуру проєкту для своєї команди.
- Вам потрібен швидкий ZIP-архів структури для початку роботи без використання CLI.
- Ви хочете поділитися пресетом папок між різними машинами або командами.

**Уникайте, коли:**
- Вам потрібно налаштувати сервери або складні права доступу; утиліта фокусується лише на структурі папок.
- Ваше дерево містить тисячі вузлів; у цьому випадку краще використовувати шаблони в коді.

## Вхідні та вихідні дані
### Вхідні дані
| Дані | Опис |
| --- | --- |
| Вузли папок і файлів | Додавайте папки або файли в реальному часі для проєктування дерева. |
| Імпорт JSON або ZIP | Завантажте існуючу структуру для зміни або повторного використання. |
| Опції скрипта | Виберіть експорт у bash або PowerShell залежно від вашого середовища. |
| Метадані пресета | Додаткові мітки або примітки для структури. |

### Вихідні дані
| Дані | Формат | Примітки |
| --- | --- | --- |
| Скрипт Bash | .sh | Скрипт для відтворення дерева в Unix-подібних системах. |
| Скрипт PowerShell | .ps1 | Скрипт для відтворення дерева у Windows. |
| ZIP-архів структури | ZIP | Порожні папки/файли, упаковані в архів для швидкої передачі. |
| JSON пресет | JSON | Багаторазовий пресет для подальшого імпорту. |

## Як використовувати
1. Створіть нове дерево або імпортуйте існуючий JSON/ZIP.
2. Додавайте папки та файли, поки структура не відповідатиме шаблону вашого проєкту.
3. Виберіть експорт у bash або PowerShell (або обидва).
4. Завантажте скрипт, ZIP або JSON пресет.
5. Запустіть скрипт у безпечній директорії, щоб побудувати структуру.

**Приклад:** Створіть структуру з папками src/, docs/, tests/ та файлом README.md; експортуйте PowerShell скрипт та ZIP для команди.
- Очікуваний результат: Надається скрипт .ps1, скрипт shell, ZIP-архів структури та JSON пресет, що представляють одне й те саме дерево.

## Точність та перевірка
- Скрипти створюють директорії при їх запуску; перевіряйте шляхи перед виконанням.
- Спеціальні символи можуть вимагати лапок у різних оболонках; налаштуйте їх, якщо ваше середовище суворе.
- Великі дерева обмежені пам'яттю браузера при експорті в ZIP.
- Уся генерація відбувається локально; зберігайте пресети під контролем версій, якщо це необхідно.

## FAQ
- **Чи змінює утиліта мій диск автоматично?** Ні. Вона лише створює скрипти або ZIP-архіви; ви запускаєте їх там, де хочете створити дерево.
- **Чи можу я ділитися пресетами?** Так. Експортуйте JSON і надішліть його своїй команді.
- **Чи працює вона офлайн?** Так. Усе відбувається у браузері.
- **Як обробляються спеціальні символи?** Скрипти екранують звичайні символи, але перевіряйте шляхи при використанні специфічних імен.
- **Чи можу я імпортувати існуюче дерево?** Так. Імпортуйте з JSON або ZIP-архіву.
