## Що вона робить
Експериментуйте з K-factors, bend deductions та положеннями нейтральної осі перед відправкою програм на листозгинальний прес. Введіть товщину, радіус та кути, щоб побачити загальну довжину розгортки та припуски на згин, що відповідають допускам ISO 2768 або ANSI.

## Коли використовувати (і коли не використовувати)
**Використовуйте, коли:**
- Ви складаєте або переглядаєте програми для листозгину і хочете перевірити припуски перед виробництвом.
- Ви хочете налаштувати K-factor або bend deductions для відповідності новій партії матеріалу або оснащенню преса.
- Вам потрібен швидкий навчальний посібник для стажерів, які вивчають, як довжина фланця змінюється при різних радіусах.

**Уникайте, коли:**
- Ви моделюєте штамповані, вальцьовані або сильно нелінійні згини, для яких потрібні дані FEA або постачальника.
- Вам потрібні автоматичні розгортки для складних деталей з багатьма згинами; виконуйте розрахунок для кожного згину та об'єднуйте результати.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Товщина матеріалу | Калібр або товщина листа, який ви згинаєте. |
| Внутрішній радіус згину | Радіус в області нейтральної осі; визначає значення припуску. |
| Кут згину | Кут після пружинення; вводьте узгоджені одиниці вимірювання. |
| Довжини фланців | Довжини полиць, прилеглих до згину, які входять до загальної довжини розгортки. |
| K-factor або bend deduction | Виберіть розрахунок на основі K-factor або відомого вирахування. |
| Нотатки про матеріал або оснащення | Необов'язкові нотатки про ширину матриці, напрямок волокон або налаштування преса. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| Загальна довжина розгортки | Числовий | Довжина для програмування або різання перед формуванням. |
| Припуск / вирахування на згин | Числовий | Обчислюється на основі товщини, радіусу та кута для вказаного K-factor. |
| Положення нейтральної осі | Числовий | Положення, виражене як коефіцієнт товщини для довідки. |
| Картка зведення | На екрані | Значення для копіювання в нотатки CAM або технологічні карти. |

## Як використовувати
1. Введіть товщину листа та внутрішній радіус згину.
2. Встановіть кут згину та довжини фланців, що потребують розгортки.
3. Виберіть, чи проводити розрахунок на основі K-factor чи bend deduction.
4. Перегляньте отриману довжину розгортки та значення припусків.
5. Скопіюйте значення у вашу програму CAM або збережіть скріншот.

**Приклад даних:** Товщина: 3 мм, Внутрішній радіус: 4 мм, Кут згину: 90 град, Фланці: 50 мм та 75 мм, K-factor: 0.38.
- Очікуваний результат: Показує довжину розгортки та припуск на згин для двополицевого згину, щоб ви могли запрограмувати прес або CAM-розгортку.

## Точність та перевірка
- Припускається вільне згинання з єдиним K-factor по всьому згину.
- Не враховує напрямок волокон або знос інструменту; перевірте на пробному зразку перед повним запуском.
- Дотримуйтесь одноманітності одиниць вимірювання; інструмент не конвертує змішані значення.
- Використовуйте тестові зразки на пресі для уточнення K-factor для кожної партії матеріалу.

## FAQ
- **Чи підтримує вона кілька згинів?** Використовуйте її для кожного згину або полиці окремо; комбінуйте результати для складних деталей.
- **Чи можу я працювати в дюймах та метричній системі?** Так. Вводьте значення в тих одиницях, які ви використовуєте; математика не залежить від одиниць вимірювання.
- **Як мені експортувати числа?** Копіюйте їх безпосередньо зі зведення або зробіть швидкий скріншот.
- **Чи працює вона офлайн?** Так. Все працює локально у вашому браузері.
- **Що якщо мій листозгин використовує таблиці вирахування на згин?** Виберіть режим bend deduction і підставте значення з таблиці, щоб побачити підсумкову довжину розгортки.
