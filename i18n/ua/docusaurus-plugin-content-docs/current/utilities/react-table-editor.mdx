# React Table Editor

Відкривайте файли CSV або XLSX, редагуйте дані безпосередньо в таблиці та експортуйте чисті таблиці локально в браузері.

<a className="button button--primary" href="/utilities/react-table-editor/" data-nobrokenlinkcheck>Відкрити утиліту</a>

## Що це робить
- Імпортує табличні дані з файлів CSV та XLSX.
- Дозволяє редагувати комірки на місці та налаштовувати рядки/стовпці.
- Підтримує клієнтський експорт назад у CSV або XLSX.
- Зберігає дані локально без завантаження на сервер.

## Коли використовувати (і коли ні)
**Використовуйте, коли:**
- Вам потрібна швидка очистка таблиць BOM, QA або виробничих специфікацій.
- Ви хочете нормалізувати електронні таблиці перед передачею в системи CAD/ERP.
- Вам потрібне редагування тільки в браузері без настільного офісного ПЗ.

**Уникайте, коли:**
- Вам потрібні складні формули та зведені таблиці.
- Вам потрібна багатокористувацька спільна робота в реальному часі.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Файл CSV/XLSX | Завантажте одну таблицю для інтерактивного редагування. |
| Ручне редагування | Оновлення комірок, заголовків стовпців та значень рядків. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| Відредагована таблиця | На екрані | Живий передпрогляд сітки з миттєвим оновленням. |
| Експортований файл | CSV/XLSX | Збереження очищеного набору даних для подальшого використання. |

## Як використовувати
1. Імпортуйте файл CSV або XLSX.
2. Перегляньте таблицю та відредагуйте комірки за потреби.
3. Додайте/видаліть рядки або стовпці, якщо ваш робочий процес вимагає зміни структури.
4. Експортуйте фінальну таблицю в CSV або XLSX.

## Точність та перевірка
- Перевірте одиниці вимірювання, роздільники та назви заголовків перед експортом.
- Повторно відкрийте експортований файл у цільовій програмі, щоб підтвердити сумісність.
- Дані залишаються в сесії вашого браузера, доки ви їх не експортуєте.

## FAQ
- **Чи завантажується мій файл на сервер?** Ні, обробка виконується локально у вашому браузері.
- **Які формати підтримуються?** CSV та XLSX.
- **Чи можна редагувати формули?** Утиліта оптимізована для редагування значень, а не для складних формул електронних таблиць.
- **Чи можна використовувати офлайн?** Якщо ресурси кешовані та доступні локально в браузері, то так.
