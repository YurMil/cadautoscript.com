## Що вона робить
Шукайте різьби ISO, UNC та UNF, потім копіюйте позначення або діаметри свердл прямо у ваше креслення. Таблиці залишаються фільтрованими у браузері, тому ви можете перемикатися між великим, дрібним або спеціальним кроком без необхідності гортати PDF-довідник.

## Коли використовувати (і коли не використовувати)
**Використовуйте, коли:**
- Вам потрібна швидка довідка по свердлу під різьбу або під прохідний отвір для креслення або карти налагодження.
- Ви хочете скопіювати правильно відформатоване позначення в CAD без ручного введення.
- Ви порівнюєте метричні та дюймові серії для підбору розміру-замінника.

**Уникайте, коли:**
- Вам потрібні конічні трубні різьби, трапецеїдальні різьби або нестандартні форми.
- Вам потрібні розрахунки класів допусків, що виходять за межі наданих довідкових значень.

## Вхідні та вихідні дані
### Вхідні дані
| Дані | Опис |
| --- | --- |
| Серія різьби | Виберіть ISO, UNC або UNF для фільтрації таблиці. |
| Номінальний розмір | Виберіть діаметр або номер калібру, який потрібно просвердлити або нарізати. |
| Крок або TPI | Виберіть великий, дрібний або конкретний крок у межах серії. |
| Клас допуску | Довідкова посадка, така як 6H/6g або клас 2; використовуйте для відповідності кресленню. |
| Тип свердла | Перемикання між свердлом під різьбу та свердлом під прохідний отвір. |

### Вихідні дані
| Дані | Формат | Примітки |
| --- | --- | --- |
| Діаметр свердла | Числовий | Рекомендований розмір свердла для обраної різьби. |
| Зовнішній/внутрішній/середній діаметри | Числовий | Довідкові розміри для контролю якості та позначень. |
| Відформатоване позначення | Текст | Готовий рядок для вставки в CAD або технологічні карти. |

## Як використовувати
1. Виберіть серію різьби та відфільтруйте потрібний номінальний розмір.
2. Виберіть крок та клас допуску.
3. Перемкніться на свердло під різьбу або прохідний отвір, щоб побачити потрібний діаметр.
4. Скопіюйте позначення або розмір свердла прямо у ваше креслення.
5. Опціонально: перемикайтеся між метричними та дюймовими списками для порівняння аналогів.

**Приклад даних:** Різьба: M12 x 1.75, Допуск: 6H, Свердло: під різьбу.
- Очікуваний результат: Повертає рекомендацію по свердлу (10.2 мм) та рядок позначення, відформатований як M12x1.75-6H.

## Точність та перевірка
- Значення відповідають загальним довідковим таблицям ISO та UNC/UNF; звіряйтеся з вашим чинним стандартом.
- Не охоплює конічні трубні різьби або спеціальні форми.
- Завжди перевіряйте розміри свердл на наявність інструменту та відповідність матеріалу перед початком різання.
- Для критичних посадок підтверджуйте допуски за офіційним стандартом або мірами довжини.

## FAQ
- **Чи можу я додавати свої рядки?** Поки ні. Використовуйте надані серії; копіюйте результати там, де це необхідно.
- **Чи включені трубні різьби?** Ні. Поточний набір охоплює лише ISO, UNC та UNF.
- **Чи працює вона офлайн?** Так. Таблиці завантажуються локально у браузері.
- **Чи можу я копіювати значення в CAD?** Так. Копіюйте позначення або розмір свердла прямо з таблиці.
- **Чи показує вона метричні та дюймові розміри?** Так. Перемикайте серії для переходу між списками.
