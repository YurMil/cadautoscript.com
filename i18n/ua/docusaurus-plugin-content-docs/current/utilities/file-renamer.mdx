## Що робить
Завантажте групу файлів, перегляньте нові імена за допомогою пошуку/заміни (включаючи регулярні вирази), додайте префікси, суфікси або нумерацію та завантажте перейменований набір у вигляді ZIP-архіву. Все працює в браузері, тому ваші файли залишаються локальними.

## Коли використовувати (і коли ні)
**Використовуйте, коли:**
- Вам потрібно впорядкувати назви креслень або додати номери замовлень перед відправкою пакета документів.
- Ви хочете масово застосувати нумерацію або префікси без написання скриптів.
- Ви надаєте перевагу швидкому офлайн-перейменуванню з отриманням готового ZIP-архіву.

**Уникайте, коли:**
- Вам потрібно перейменувати тисячі файлів на диску; у цьому випадку краще використовувати CLI-скрипт.
- Вам необхідно зберегти ієрархію вкладених папок; об'єднання файлів в один рівень може бути небажаним.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Файли для перейменування | Перетягніть файли, які хочете обробити. |
| Правила пошуку/заміни | Використовуйте звичайні рядки або регулярні вирази для трансформації імен. |
| Префікс/суфікс | Додайте номери замовлень, ревізії або інші теги. |
| Нумерація | Встановіть початок, крок та доповнення нулями для порядкових номерів. |
| Регістр | Опціональне перетворення у верхній/нижній регістр або kebab-case. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| Таблиця попереднього перегляду | На екрані | Порівняння старих та нових імен перед експортом. |
| Перейменовані файли | ZIP | Архів для завантаження з оновленими іменами файлів. |

## Як використовувати
1. Перетягніть файли для перейменування.
2. Застосуйте правила пошуку/заміни, префікси, суфікси або нумерацію.
3. Перевірте таблицю попереднього перегляду, щоб переконатися у відсутності конфліктів імен.
4. Завантажте ZIP-архів з перейменованими файлами.
5. Відправте або заархівуйте перейменований пакет.

**Приклад:** Завантажте `P-001.pdf`, `P-002.pdf`; знайдіть 'P-' та замініть на 'FAB-', додайте префікс `2025_`, почніть нумерацію з 10.
- Очікуваний результат: Завантажується ZIP-архів з файлами `2025_FAB-10.pdf` та `2025_FAB-11.pdf`.

## Точність та перевірка
- Перейменування відбувається в браузері; зберігайте оригінали, поки не перевірите ZIP.
- Регулярні вирази — потужний інструмент, спочатку протестуйте їх на невеликому наборі файлів.
- Конфлікти імен обробляються в попередньому перегляді; вирішіть їх перед експортом.
- Великі пакети обмежені пам'яттю браузера; за потреби розділяйте їх.

## FAQ
- **Чи працюють регулярні вирази (regex)?** Так. Використовуйте стандартні регулярні вирази JavaScript для складного перейменування.
- **Чи зберігається структура папок?** Файли об'єднуються в один ZIP-архів з новими іменами без збереження ієрархії папок.
- **Чи завантажуються дані на сервер?** Ні. Всі процеси виконуються локально у вашому браузері.
- **Скільки файлів можна перейменувати за раз?** Це залежить від пам'яті браузера; дуже великі набори краще розділяти на частини.
- **Що відбувається з вмістом файлів?** Вміст залишається незмінним; оновлюються лише імена файлів.
