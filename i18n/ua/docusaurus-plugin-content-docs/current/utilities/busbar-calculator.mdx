## Що робить утиліта

Утиліта призначена для попередніх розрахунків шин у низьковольтних шафах і розподільчих збірках. Користувач задає тип системи AC/DC, напругу, струм, кількість фаз, матеріал, розміри прямокутної шини, кількість шин на фазу, компоновку, умови охолодження та параметри короткого замикання. Після кожної зміни перераховуються густина струму, опір, втрати, прогноз температури, габарит каналу, статус зазорів і запас за КЗ.

Застосунок підключено як самостійний micro-app у `static/utility-apps/busbar-calculator`. Оболонка CAD AutoScript показує його так само, як інші утиліти сайту: через сторінку каталогу, статтю, коментарі, реакції та спільну систему доступу.

## Коли використовувати

- Для попереднього вибору мідних або алюмінієвих прямокутних шин.
- Для порівняння однієї, двох, трьох або чотирьох шин на фазу до компонування шафи.
- Для оцінки втрат на метр і усталеної температури за вибраного охолодження.
- Для швидкої перевірки фазних зазорів і відступів, які потребують інженерного перегляду.
- Для підготовки PDF-нотатки до обговорення проєкту або QA-перевірки.

## Вхідні та вихідні дані

| Розділ | Ввід | Результат |
| --- | --- | --- |
| Електрика | AC/DC, напруга, струм, частота, фази | Густина струму, опір, втрати на метр |
| Матеріал і профіль | Мідь, алюміній, ширина, товщина, шин на фазу | Площа, маса, ранжування кандидатів |
| Компоновка | Горизонтально/вертикально, flatwise/edgewise, зазори | Схема перерізу, центри фаз, габарит каналу |
| Середовище | Температура, охолодження, множник корпусу | Усталена температура та графік прогнозу |
| Коротке замикання | RMS струм, тривалість, піковий струм, крок опор | Статус теплової та механічної перевірки |
| Звіти | Проєкт, шафа, тег, ревізія, інженер | PDF, JSON імпорт/експорт, CAD payload |

## Важливі обмеження

Вбудовані властивості матеріалів, рейтинги профілів, охолодження та правила зазорів позначені як example-only. Вони допомагають протестувати робочий процес, але не є сертифікованою розрахунковою базою. Для реального випуску замініть їх затвердженими DIN, IEC, каталогами виробника або проєктними даними та перевірте розрахунок за правилами вашої організації.

## Типовий процес

1. Заповніть дані проєкту та електричні параметри.
2. Виберіть мідь або алюміній і перегляньте запропоновані профілі.
3. Налаштуйте кількість шин на фазу, орієнтацію, фазні зазори та відступи корпусу.
4. Перевірте переріз, густину струму, втрати та температурний прогноз.
5. Додайте параметри КЗ, якщо вони відомі.
6. Експортуйте PDF-звіт або JSON-конфігурацію для подальшої перевірки.
