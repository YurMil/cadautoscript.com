## Що це робить
Перетягуйте кілька PDF-файлів, змінюйте порядок або повертайте сторінки та експортуйте чистий об'єднаний пакет повністю у браузері. Використовуйте його для впорядкування наборів креслень або перевірки пакетів без надсилання файлів у хмарні сервіси.

## Коли використовувати (і коли не використовувати)
**Використовуйте, коли:**
- Вам потрібно змінити порядок або повернути сторінки у пакеті креслень перед випуском.
- Ви хочете об'єднати кілька PDF в один без встановлення настільних інструментів.
- Ви віддаєте перевагу локальній обробці для конфіденційних креслень.

**Уникайте, коли:**
- Вам потрібно редагувати текст, приховувати вміст або ставити підписи (використовуйте PDF Batch Signer для штампів).
- Ваші файли надзвичайно великі та краще обробляються спеціальним настільним редактором PDF.

## FAQ
- **Чи стискає він або змінює якість?** Ні, вихідні дані відповідають вихідним сторінкам.
- **Чи можна видаляти сторінки?** Зміна порядку та поворот — основні дії; експортуйте лише ті сторінки, які ви включили.
- **Чи завантажуються дані?** Ні. Об'єднання відбувається локально у вашому браузері.
- **Який розмір файлу він може обробити?** Залежить від пам'яті вашого браузера.
- **Чи можна тут підписувати документи?** Використовуйте PDF Batch Signer для штампів.
