## Що це робить
Обирайте технологічні з'єднання, розміри камери, параметри вентиляції та дренажу, а також матеріали. Переглядайте живий SVG-ескіз та експортуйте PDF-специфікацію (datasheet), яка фіксує всі параметри для закупівлі або перевірки постачальником.

## Коли використовувати (і коли ні)
**Використовуйте, коли:**
- Ви складаєте специфікацію магнітного покажчика рівня для запиту ціни або внутрішньої перевірки.
- Ви хочете перевірити міжосьову відстань (center-to-center) та стандарти з'єднань перед замовленням.
- Вам потрібен швидкий PDF-datasheet для обміну даними з відділами трубопроводів або КВПіА.

**Уникайте, коли:**
- Вам потрібні сертифіковані розрахунки тиску або розрахунки поплавця від виробника.
- Ви налаштовуєте радари з направленою хвилею (guided wave radar) або немагнітні прилади рівня.

## Вхідні та вихідні дані
### Вхідні дані
| Параметр | Опис |
| --- | --- |
| Process connection standard and size | Опції DIN, ANSI, під зварювання або різьбові для бічних з'єднань. |
| Center-to-center dimension | Довжина вимірювальної камери, що використовується для масштабування ескізу. |
| Top and bottom connections | Варіанти вентиляції та дренажу (заглушка, клапан або фланець). |
| Materials and ratings | Матеріал камери, клас тиску фланців та припущення щодо питомої ваги середовища. |
| Instrumentation options | Перемикачі, віддалені трансмітери, обігрів та вподобання щодо індикатора. |
| Project metadata | Тег (Tag), номер лінії, замовник та примітки для специфікації. |

### Вихідні дані
| Результат | Формат | Примітка |
| --- | --- | --- |
| PDF datasheet | PDF | Технічний лист з вибором параметрів та масштабованим ескізом. |
| Live SVG preview | SVG | Ескіз на екрані, що оновлюється при введенні даних. |
| Connection summary | На екрані | Список параметрів процесу, вентиляції та дренажу для перевірки. |

## Як використовувати
1. Оберіть стандарт, розмір та рейтинг технологічного з'єднання.
2. Введіть міжосьову відстань, а також деталі вентиляції та дренажу.
3. Встановіть матеріали, питому вагу середовища та опціональні датчики або трансмітери.
4. Додайте метадані проекту для простежуваності.
5. Перевірте ескіз та експортуйте PDF-специфікацію.

**Приклад набору даних:** Бічні з'єднання: DIN DN25 PN40 RF, Міжосьова: 1800 мм, Верх: 1/2 in NPT plug, Низ: 1/2 in NPT valve, Матеріал: 316L, Опції: датчики увімкнені, обігрів вимкнений, Тег: MLG-101.
- Очікуваний результат: Генерується PDF-специфікація з обраними з'єднаннями, розмірами, матеріалами та живим ескізом для MLG-101.

## Точність та перевірка
- Розміри на ескізі мають ілюстративний характер; уточнюйте фінальні розміри у постачальника перед виготовленням.
- Класи тиску та температури мають бути перевірені на відповідність вашим стандартам проектування.
- Питома вага та параметри поплавця прийняті за замовчуванням; підтвердьте їх даними процесу, якщо це критично.
- Файли залишаються локальними до моменту завантаження PDF.

## FAQ
- **Чи можна перемикатися між метричною та імперською системами?** Так. Вводьте значення у ваших одиницях; ескіз адаптується.
- **Чи готовий PDF для офіційного подання?** Це попередня специфікація; запитуйте сертифіковані креслення у виробника.
- **Чи зберігаються мої теги?** Ні. Дані очищаються при закритті сторінки; зберігайте PDF.
- **Чи можна налаштувати типи дренажу та вентиляції?** Так. Обирайте заглушку, клапан або фланець.
- **Чи надсилаються дані на сервер?** Ні. Усі розрахунки локальні.
