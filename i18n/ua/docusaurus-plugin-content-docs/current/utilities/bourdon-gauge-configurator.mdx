## Що вона робить
Вибирайте розмір циферблата, діапазон тиску, стандарт з'єднання, заповнення корпусу та аксесуари для манометра з трубкою Бурдона. Переглядайте креслення манометра, перемикайте варіанти сифонів або клапанів та експортуйте лист технічних даних у PDF з вашим вибором.

## Коли використовувати (і коли ні)
**Використовуйте, коли:**
- Ви готуєте специфікацію манометра для цінової пропозиції або внутрішнього узгодження.
- Вам потрібно швидко порівняти варіанти з'єднань або заповнення за допомогою живого прев'ю.
- Вам потрібен PDF-лист для відправки постачальникам без очікування креслень від конструкторського відділу.

**Уникайте, коли:**
- Вам потрібні сертифіковані показники тиску або схвалення, що виходять за межі попереднього листа даних.
- Ви налаштовуєте електронні датчики або мембранні розділювачі (тут не розглядаються).

## Входи та виходи
### Входи
| Вхід | Опис |
| --- | --- |
| Розмір циферблата | Номінальний діаметр шкали манометра. |
| Діапазон тиску та одиниці | Виберіть попередньо встановлені діапазони або введіть власний. |
| Розташування та стандарт з'єднання | Нижнє/заднє кріплення з DIN, ANSI, NPT або іншими варіантами. |
| Заповнення корпусу та вікно | Сухі або заповненні корпуси, плюс матеріал вікна. |
| Аксесуари | Сифон, клапан, фланець або інші опції для включення. |
| Метадані проєкту | Тег, номер лінії та примітки для листа даних. |

### Виходи
| Вихід | Формат | Примітки |
| --- | --- | --- |
| PDF datasheet | PDF | Зведення по манометру з прев'ю та обраними параметрами. |
| Gauge preview | На екрані | Живе креслення, яке оновлюється в міру зміни налаштувань. |

## Як використовувати
1. Виберіть розмір циферблата та діапазон тиску (попередньо встановлений або власний).
2. Виберіть розташування з'єднання, стандарт та заповнення корпусу.
3. Перемкніть аксесуари, такі як сифон, клапан або фланець.
4. Додайте теги проєкту або примітки.
5. Експортуйте лист технічних даних у PDF для перевірки або подання.

**Приклад даних:** Циферблат: 100 мм, Діапазон: від 0 до 10 бар, З'єднання: заднє G 1/2, Заповнення: гліцерин, Аксесуар: сифон, Тег: PG-204.
- Очікуваний результат: Створює PDF-лист даних з обраним діапазоном, з'єднанням, заповненням, аксесуаром та зображенням прев'ю для PG-204.

## Точність та перевірка
- Лист даних є попереднім; уточнюйте показники тиску та матеріали, що контактують з середовищем, у виробника.
- Діапазони та одиниці вводяться користувачем; переконайтеся, що вони відповідають вашим технологічним межам.
- Аксесуари мають ілюстративний характер; перевірте зачеплення різьби та монтажні зазори перед встановленням.
- Всі розрахунки залишаються локальними; збережіть PDF для архівування вашого вибору.

## FAQ
- **Чи можу я ввести власний діапазон?** Так. Використовуйте власний діапазон, коли попередньо встановлені варіанти не відповідають вашим потребам.
- **Чи підтримуються імперські одиниці вимірювання?** Так. Вводьте psi або bar за потреби; у листі даних буде вказано те, що ви ввели.
- **Чи можу я додати логотип своєї компанії?** Використовуйте експортований PDF і додайте брендинг пізніше, якщо це необхідно.
- **Чи відповідає прев'ю реальному масштабу?** Воно має ілюстративний характер; запитуйте сертифіковані креслення для отримання точних розмірів.
- **Чи завантажуються мої дані?** Ні. Все працює в браузері.
