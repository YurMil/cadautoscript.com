## Що це робить
Створюйте серійні бирки обладнання з підтримкою QR, налаштовуваними матеріалами, глибиною гравіювання та рядками метаданих. Попередньо перегляньте пластину в 3D, налаштуйте розміри та шари брендингу, а потім експортуйте макети у високій роздільній здатності PNG або SVG для лазерного маркування або УФ-друку.

## Коли використовувати (і коли ні)
**Використовуйте, коли:**
- Вам потрібен швидкий спосіб генерації серійних бирок для обладнання або інструментів.
- Ви хочете передати готовий векторний макет у друкарню або гравірувальну майстерню.
- Ви перевіряєте читабельність QR-коду при різних розмірах перед запуском у виробництво.

**Уникайте, коли:**
- Вам потрібен серійний випуск із підтримкою бази даних або відстеження виробництва.
- Вам потрібні прямі драйвери для принтера або розкладка для масового друку.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Дані QR | URL, ID активу або текст, закодований у QR. |
| Метадані бирки | Назва активу, серійний номер, попередження або інший текст. |
| Розмір і товщина пластини | Загальні розміри плюс пресети глибини гравіювання. |
| Пресет матеріалу | Візуальний стиль для сталевих, алюмінієвих, пластикових або пофарбованих пластин. |
| Налаштування макета | Розмір QR, поля та типографіка для друкованої пластини. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| Макет шильдика | PNG/SVG | Експорт у високій роздільній здатності для гравіювання або друку. |
| 3D предпросмотр | Viewport | Візуальна перевірка пропорцій пластини та глибини гравіювання. |

## Як використовувати
1. Введіть дані для QR-коду та метадані, які ви хочете бачити на бирці.
2. Встановіть розміри пластини, поля та глибину гравіювання.
3. Виберіть пресет матеріалу або оздоблення.
4. Перегляньте 3D-модель та за потреби відрегулюйте розміри.
5. Експортуйте макет у PNG або SVG для виробництва.

**Приклад набору даних:** Бирка активу P-101 з QR, що вказує на https://cadautoscript.com/utilities/qr-nameplate/, розмір 100 x 40 мм, вигляд під сталь, глибина гравіювання 0.3 мм.
- Очікуваний результат: Експорт PNG та SVG бирки плюс предпросмотр, що показує пропорції та читабельні поля QR.

## Точність та перевірка
- Переконайтеся, що роздільна здатність експортованого PNG/SVG відповідає вимогам вашого принтера або гравера.
- Залишайте вільну зону навколо QR для надійного сканування.
- Протестуйте один надрукований зразок перед запуском усієї партії, щоб підтвердити читабельність.
- Весь рендеринг виконується локально; зберігайте копії експорту для простежуваності.

## FAQ
- **Чи можна змінювати матеріали?** Так. Виберіть пресет, щоб візуалізувати сталеві, пофарбовані або пластикові пластини.
- **QR-код векторний чи растровий?** Експорт у SVG — векторний; PNG — растровий високої роздільної здатності.
- **Чи працює це офлайн?** Так. Генерація макета відбувається в браузері.
- **Як зберегти QR-код сканованим?** Дотримуйтесь зони відступу (quiet zone) і уникайте зменшення коду нижче меж вашого сканера.
- **Чи можна серійно випускати багато бирок одразу?** Використовуйте генератор для кожної бирки та повторно використовуйте шаблон даних.
