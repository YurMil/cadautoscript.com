## Що вона робить
Створюйте підпис для багаторазового використання (малюючи, друкуючи або завантажуючи скан), розміщуйте його в режимі попереднього перегляду та застосовуйте до всіх сторінок вашого пакета PDF. Опціональний аналіз Gemini може зчитувати основні написи (штампи), якщо ви надасте власний API key; в іншому випадку все залишається локально.

## Коли використовувати (і коли не використовувати)
**Використовуйте, коли:**
- Вам потрібно поставити штамп на кілька креслень або звітів за один прохід без використання хмарних сервісів.
- Ви хочете забезпечити однакове розміщення підпису на кожній сторінці пакета.
- Вам потрібен швидкий ZIP-архів підписаних PDF для відправки постачальникам або у відділ контролю якості (QA).

**Уникайте, коли:**
- Вам потрібні криптографічні підписи або підписи на основі сертифікатів.
- Ваші сторінки мають дуже різні розміри, що потребують унікального розміщення для кожної сторінки.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Пакет PDF | Один або кілька PDF-файлів для нанесення штампа за один раз. |
| Джерело підпису | Намалюйте, надрукуйте або завантажте зображення підпису для повторного використання. |
| Розміщення та масштаб | Встановіть положення та розмір підпису в режимі попереднього перегляду перед застосуванням. |
| Опціональний Gemini API key | Якщо ви хочете витягти дані з основного напису; в іншому випадку все залишається офлайн. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| Підписані PDF | ZIP | Усі вхідні файли зі штампом в одному і тому ж місці. |
| Попередній перегляд | На екрані | Візуальна перевірка нанесеного підпису. |

## Як використовувати
1. Завантажте PDF-файли, які потрібно підписати.
2. Створіть або завантажте підпис, налаштуйте його положення та розмір.
3. Опціонально додайте Gemini API key, якщо хочете витягти метадані з основного напису креслення.
4. Застосуйте підпис до всіх сторінок.
5. Завантажте ZIP-архів підписаних PDF.

**Приклад даних:** Завантажте десять PDF-креслень, намалюйте підпис, розмістіть його за 20 мм від правого нижнього кута, залиште Gemini вимкненим та експортуйте ZIP.
- Очікуваний результат: Завантажується ZIP-архів, що містить усі креслення з однаковим видимим розташуванням підпису на кожній сторінці.

## Точність та перевірка
- Наносить графічний штамп, а не цифровий сертифікат; перевірте допустимість використання для регламентованих документів.
- Змішані формати сторінок можуть вимагати швидкої візуальної перевірки після підписання.
- Опціональне витягування даних Gemini використовує ваш ключ на стороні клієнта; залиште поле порожнім, щоб все залишалося офлайн.
- Зберігайте оригінали, якщо вам потрібен аудит; інструмент перезаписує лише копії, що завантажуються.

## FAQ
- **Чи є це цифровим сертифікатом?** Ні. Це графічний підпис, що наноситься локально.
- **Чи будуть мої файли кудись завантажуватися?** Ні. Процес підписання виконується за допомогою pdf-lib та JSZip прямо у вашому браузері.
- **Чи можу я обробляти сторінки різних розмірів?** Так, але перед експортом усього набору перевірте розміщення на тестовій сторінці.
- **Як мені змінити штамп пізніше?** Завантажте файли знову, налаштуйте підпис та виконайте експорт повторно.
- **Щодо міток часу?** Додайте текст із датою всередину зображення підпису або запустіть процес заново з оновленою міткою.
