# Engineering Prompt Catalog

Переглядайте куровану бібліотеку шаблонів промптів для КВПіА, механічного проектування та закупівель.

<a className="button button--primary" href="/utilities/engineering-prompt-catalog/" data-nobrokenlinkcheck>Відкрити утиліту</a>

## Що робить
- Групує промпти за дисциплінами та підкатегоріями для швидкої фільтрації.
- Виділяє плейсхолдери, щоб ви могли замінити їх реальними значеннями за секунди.
- Копіює промпти в буфер обміну або завантажує їх у форматі Markdown.
- Використовує наочну таблицю для швидкого переходу між основними категоріями.

## Коли використовувати (і коли ні)
**Використовуйте, коли:**
- Вам потрібна швидка та послідовна структура промпту для технічних завдань.
- Ви хочете стандартизувати спосіб запиту специфікацій, розрахунків або RFQ у вашій команді.
- Вам потрібен швидкий шаблон промпту без відкриття бібліотеки документів.

**Уникайте, коли:**
- Робота вимагає конфіденційних даних, які не повинні потрапляти в інструменти ШІ.
- Вам потрібен повний контекст проекту або вилучення даних із креслень.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Фільтр категорій | Виберіть КВПіА, Механіка або Закупівлі, щоб звузити результати. |
| Фільтр підкатегорій | Перейдіть у такі області, як Розрахунок клапанів, SolidWorks або RFQ. |
| Пошук | Знайдіть промпти за ключовими словами в цілі або тексті промпту. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| Картки промптів | На екрані | Готові до копіювання шаблони з плейсхолдерами. |
| Копія в буфер | Простий текст | Копіювання повного промпту в один клік. |
| Файл Markdown | .md | Ім'я завантаженого файлу відповідає назві промпту. |

## Як використовувати
1. Відкрийте утиліту та виберіть дисципліну на бічній панелі.
2. Виберіть підкатегорію або введіть ключове слово в рядку пошуку.
3. Натисніть **Copy**, щоб використати промпт, або **Save MD**, щоб завантажити його.
4. Замініть плейсхолдери в дужках значеннями, специфічними для вашого проекту.

**Приклад:** Відфільтруйте **КВПіА → Розрахунок клапанів**, скопіюйте промпт для розрахунку Cv, замініть `[P1]`, `[P2]` та `[Q]`, потім вставте у свій інструмент ШІ.

## Точність та перевірка
- Промпти є лише шаблонами. Завжди перевіряйте результати на відповідність вашим стандартам та розрахункам.
- Видаляйте конфіденційні дані перед вставкою промптів у будь-які зовнішні системи.
- Дотримуйтесь єдності систем одиниць при заповненні плейсхолдерів.

## FAQ
- **Чи працює він офлайн?** Так. Бібліотека промптів вбудована і працює повністю в браузері.
- **Чи можна додати власні промпти?** Поки ні. Цей каталог є фіксованим стартовим набором.
- **Чи будуть мої дані зберігатися або завантажуватися?** Ні. Копіювання та завантаження відбуваються локально.
- **Чому плейсхолдери в дужках?** Їх легко сканувати та замінювати перед використанням.
