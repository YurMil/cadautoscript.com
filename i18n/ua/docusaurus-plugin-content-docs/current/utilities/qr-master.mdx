## Що це робить
Використовуйте камеру, вставлені зображення або завантаження для сканування QR-кодів та розповсюджених штрих-кодів, а потім створюйте власні коди для WiFi, посилань або контактів. Зберігайте локальну історію з можливістю імпорту та експорту, щоб дані залишалися мобільними без хмарної синхронізації.

## Коли використовувати (і коли ні)
**Використовуйте, коли:**
- Вам потрібно швидко відсканувати бирки активів або штрих-коди без встановлення додатка.
- Ви хочете створити QR-код для WiFi або посилання для швидкої передачі.
- Вам потрібен легкий автономний спосіб логування сканувань та їх експорту в JSON.

**Уникайте, коли:**
- Вам потрібні функції інвентаризації корпоративного рівня або хмарна синхронізація.
- Освітлення або якість камери занадто погані для надійного зчитування штрих-коду.

## Вхідні та вихідні дані
### Вхідні дані
| Вхід | Опис |
| --- | --- |
| Камера або завантажене зображення | Пряме сканування або імпорт зображення для декодування. |
| Ручне введення | Текст, URL-адреси, облікові дані WiFi або контактні дані для кодування. |
| Імпорт історії | Завантаження попередніх сканувань з JSON для безперервності роботи. |

### Вихідні дані
| Вихід | Формат | Примітки |
| --- | --- | --- |
| Декодовані результати | Текст | Вміст відсканованих QR або штрих-кодів. |
| Згенеровані коди | PNG | Зображення QR або штрих-кодів для завантаження та обміну. |
| Історія сканування | JSON | Експорт минулих сканувань, збережених локально. |

## Як використовувати
1. Дозвольте доступ до камери або перетягніть зображення для сканування.
2. Перегляньте декодовані дані та, за потреби, збережіть їх в історію.
3. Введіть посилання, логін WiFi або текст для генерації нового коду.
4. Завантажте PNG або збережіть в історії.
5. Експортуйте історію в JSON, якщо вам потрібна резервна копія.

**Приклад набору даних:** Відскануйте штрих-код бирки обладнання, щоб отримати серійний номер, потім створіть QR-код WiFi для SSID 'Plant-Guest' з паролем та експортуйте історію.
- Очікуваний результат: Повертає текст відсканованого серійного номера, PNG з QR-кодом WiFi для завантаження та запис в історії JSON, який можна зберегти.

## Точність та перевірка
- Якість сканування залежить від фокусування вашої камери та освітлення.
- Всі скани залишаються локальними; експортуйте історію, якщо потрібно змінити пристрій.
- Згенеровані коди відповідають загальним специфікаціям QR/штрих-кодів; перевірте швидким тестовим скануванням перед використанням.
- Очищення історії видаляє локальні дані; зберігайте експортні файли для архіву.

## FAQ
- **Які формати підтримуються?** QR-коди та розповсюджені штрих-коди; протестуйте зразок, якщо вам потрібна конкретна символіка.
- **Чи працює це офлайн?** Так. Сканування та генерація виконуються в браузері.
- **Де зберігається історія?** У пам'яті вашого браузера, доки ви її не експортуєте або не очистите.
- **Чи можна сканувати зображення замість камери?** Так. Вставте або завантажте зображення, і декодер його прочитає.
- **Чи можна експортувати результати сканування?** Так. Експортуйте історію у форматі JSON для резервного копіювання або спільного використання.
