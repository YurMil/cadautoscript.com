## Що вона робить

Перетягніть лог-файл, експортований з цифрового калібратора тиску **WIKA CPG1500**, і миттєво отримайте:

- **Картка ідентифікації пристрою** — серійний номер, модель, версія прошивки, дати калібрування та метадані оператора, вилучені з заголовка файлу.
- **Сітка даних вимірювань** — таблиця всіх показань тиску/температури з відмітками часу, доступна для пошуку та сортування.
- **Графік тиску** — інтерактивний лінійний графік записаної кривої тиску у часі.
- **Готовий до друку звіт КЯ** — багатосторінковий макет, оптимізований для друку (портретна орієнтація A4 для таблиць, альбомна A4 для графіків), який можна відправити прямо на принтер або зберегти у PDF.

Все працює на стороні клієнта за допомогою React та Material UI. Дані не залишають браузер.

## Коли використовувати (і коли ні)

**Використовуйте, коли:**
- Вам потрібно переглянути логи калібрування WIKA CPG1500 на будь-якій машині з браузером.
- Ви хочете швидко візуально перевірити криву тиску перед оформленням сертифіката.
- Вам потрібно роздрукувати або зберегти у PDF відформатований звіт КЯ для додавання до супровідної документації.
- Ви хочете шукати або сортувати результати вимірювань без імпорту необробленого файлу в Excel.

**Уникайте, коли:**
- Ваші лог-файли отримані з іншої моделі калібратора (парсер специфічний для CPG1500).
- Вам потрібна пакетна обробка десятків логів одночасно (завантажуйте по одному файлу за раз).

## Входи та виходи

### Входи
| Вхід | Опис |
| :--- | :--- |
| **Лог-файл** | Файл `.log` або `.txt`, експортований з калібратора WIKA CPG1500. |

### Виходи
| Вихід | Формат | Примітки |
| :--- | :--- | :--- |
| **Ідентифікація пристрою** | Картка на екрані | Серійний номер, модель, прошивка, дати калібрування, оператор. |
| **Таблиця вимірювань** | Сітка на екрані | Показання тиску та температури з відмітками часу та пошуком. |
| **Графік тиску** | Інтерактивний графік | Лінійний графік залежності тиску від часу. |
| **Звіт КЯ** | Друк / PDF | Багатосторінковий звіт, оптимізований для A4, через діалог друку браузера. |

## Як використовувати

1. **Відкрийте утиліту** і клікніть по області завантаження або перетягніть лог-файл CPG1500.
2. **Перевірте картку ідентифікації пристрою** — підтвердіть правильність серійного номера, моделі та дат калібрування.
3. **Перегляньте сітку вимірювань** — використовуйте поле пошуку для фільтрації рядків або клікайте по заголовках стовпців для сортування.
4. **Вивчіть графік тиску** — наводьте на точки даних для отримання точних значень; використовуйте зум або панорамування, якщо доступно.
5. **Роздрукуйте звіт** — натисніть кнопку друку в браузері (`Ctrl+P` / `Cmd+P`). Макет автоматично переключиться на звіт, оптимізований для A4, з розривами сторінок для картки ідентифікації, таблиці даних та графіка.

### Приклад робочого процесу
Завантажте лог-файл нещодавнього тесту тиску → переконайтеся, що серійний номер пристрою збігається з сертифікатом калібрування → перевірте криву тиску на наявність аномалій → роздрукуйте відформатований звіт і прикріпіть його до супровідного листа.

## Макет друку звіту

Стиль друку створює чистий багатосторінковий звіт КЯ:

| Сторінка | Зміст | Орієнтація |
| :--- | :--- | :--- |
| 1 | Ідентифікація пристрою + короткий підсумок вимірювань | Портретна (A4) |
| 2+ | Повна таблиця даних вимірювань | Портретна (A4) |
| Сторінка графіка | Графік тиску з легендою | Альбомна (A4) |

:::tip
Використовуйте "Зберегти як PDF" у діалоговому вікні друку вашого браузера, щоб архівувати звіт у цифровому вигляді разом з вашими калібрувальними сертифікатами.
:::

## Точність та конфіденційність

- **Тільки вилучені дані** — утиліта не змінює оригінальний лог-файл; вона зчитує та відображає значення як є.
- **Жодних завантажень** — весь парсинг відбувається в браузері за допомогою клієнтського JavaScript. Жодні дані не передаються на сервер.
- **Тільки в межах сесії** — закрийте вкладку, і всі оброблені дані зникнуть. Збережіть або роздрукуйте звіт перед закриттям.
- **Звіряйте з джерелом** — завжди перевіряйте критичні значення (серійний номер, тестовий тиск) з оригінальним лог-файлом та калібрувальним сертифікатом.

## FAQ

- **Які формати лог-файлів підтримуються?** Лог-файли, експортовані з цифрових калібраторів тиску WIKA CPG1500 (`.log` / `.txt`).
- **Чи завантажуються мої дані на сервер?** Ні. Все залишається в браузері.
- **Чи можу я роздрукувати або зберегти звіт?** Так. Використовуйте `Ctrl+P` / `Cmd+P` для друку або збереження у PDF. Макет оптимізовано для паперу формату A4.
- **Чи працює це офлайн?** Так, після завантаження сторінки підключення до інтернету не потрібне.
- **Чи можна аналізувати кілька файлів одночасно?** Завантажуйте по одному файлу за раз; оновіть або очистіть сторінку для аналізу іншого лога.
- **Що якщо мій лог-файл не розпізнається?** Парсер специфічний для формату CPG1500. Файли з інших приладів можуть не розпізнаватися. Відкрийте задачу на GitHub, якщо вважаєте, що ваш файл CPG1500 має працювати, але не працює.
