# Огляд CAD AutoScript

CAD AutoScript — це орієнтований на документацію центр для макросів SolidWorks, розрахункових інструментів для виробництва та інструментів контролю якості. Цей сайт побудований на **Docusaurus + MDX**, тому кожна утиліта задокументована поруч із її інтерактивним React-компонентом.

## Що тут знаходиться

- **Макроси SolidWorks**, що охоплюють експорт специфікацій (BOM), перевірку основних написів та помічники по конфігурації.
- **Веб-калькулятори**, які працюють повністю в Chromium (Pipe Cutter, Shell Rolling, QR-теги та багато іншого).
- **Генератори QA** для парсингу PDF, відстеження серійних номерів та автоматизації звітів.
- **Нотатки про релізи та рецепти**, щоб інженери в цеху знали, як і коли використовувати кожен інструмент.

:::tip Тільки Chromium
Всі утиліти постачаються як статичні ресурси та очікують браузер на базі Chromium (Chrome, Edge, Arc тощо) з увімкненими WebGL 2 та WebAssembly.
:::

## Швидкий старт для розробників

1. **Встановлення залежностей**
   ```bash
   npm install
   ```
2. **Локальний запуск документації**
   ```bash
   npm start
   ```
3. **Редагування контенту**
   - Сторінки Markdown знаходяться в `docs/`
   - Компоненти React знаходяться в `src/`
   - Автономні пакети утиліт знаходяться в `static/utility-apps/`
   - Спільні ресурси оболонки утиліт знаходяться в `static/utilities/`

Docusaurus миттєво перезавантажує зміни. Коли ви будете готові до публікації, запустіть `npm run build` і розгорніть вміст `build/` на GitHub Pages.

## Вбудовування живих утиліт

MDX дозволяє нам імпортувати React-компоненти або утиліти типу iframe безпосередньо на сторінки документації. Див. [Embedding calculators](utilities/embed-calculators.md) для ознайомлення з тим, як загортати додатки з `/utilities/*` або створювати спеціальні віджети React.
