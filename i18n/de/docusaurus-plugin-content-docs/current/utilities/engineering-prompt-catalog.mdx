# Engineering Prompt Catalog

Durchsuchen Sie eine kuratierte Bibliothek von Prompt-Vorlagen für MSR-Technik (I&C), mechanische Konstruktion und Beschaffung.

<a className="button button--primary" href="/utilities/engineering-prompt-catalog/" data-nobrokenlinkcheck>Utility öffnen</a>

## Funktionen
- Gruppiert Prompts nach Disziplinen und Unterkategorien für schnelles Filtern.
- Hebt Platzhalter hervor, damit Sie diese in Sekunden durch reale Werte ersetzen können.
- Kopiert Prompts in die Zwischenablage oder lädt sie als Markdown herunter.
- Nutzt eine Übersichtstabelle zum schnellen Springen zwischen den Hauptkategorien.

## Wann man es verwendet (und wann nicht)
**Verwenden Sie es, wenn:**
- Sie eine schnelle, konsistente Prompt-Struktur für technische Aufgaben benötigen.
- Sie die Art und Weise standardisieren möchten, wie Ihr Team nach Spezifikationen, Berechnungen oder RFQs fragt.
- Sie eine schnelle Prompt-Vorlage benötigen, ohne eine Dokumentenbibliothek zu öffnen.

**Vermeiden Sie es, wenn:**
- Die Arbeit proprietäre Daten erfordert, die nicht in KI-Tools eingegeben werden sollten.
- Sie den vollen Projektkontext oder eine Datenextraktion aus Zeichnungen benötigen.

## Eingaben und Ausgaben
### Eingaben
| Eingabe | Beschreibung |
| --- | --- |
| Kategoriefilter | Wählen Sie MSR, Mechanik oder Beschaffung, um die Ergebnisse einzugrenzen. |
| Unterkategoriefilter | Vertiefen Sie in Bereiche wie Ventilbemessung, SolidWorks oder RFQ. |
| Suche | Finden Sie Prompts nach Schlüsselwörtern im Ziel oder Haupttext. |

### Ausgaben
| Ausgabe | Format | Hinweise |
| --- | --- | --- |
| Prompt-Karten | Auf dem Bildschirm | Kopierfertige Vorlagen mit Platzhaltern. |
| In Zwischenablage kopieren | Nur-Text | Kopiert den vollständigen Prompt mit einem Klick. |
| Markdown-Datei | .md | Die heruntergeladene Datei verwendet den Prompt-Titel als Dateinamen. |

## Bedienungsanleitung
1. Öffnen Sie das Utility und wählen Sie eine Disziplin in der Seitenleiste.
2. Wählen Sie eine Unterkategorie oder geben Sie ein Schlüsselwort in die Suchleiste ein.
3. Klicken Sie auf **Copy**, um den Prompt zu verwenden, oder auf **Save MD**, um ihn herunterzuladen.
4. Ersetzen Sie die Platzhalter in Klammern durch projektspezifische Werte.

**Beispiel:** Filtern Sie **MSR-Ingenieur → Ventilbemessung**, kopieren Sie den Cv-Berechnungs-Prompt, ersetzen Sie `[P1]`, `[P2]` und `[Q]` und fügen Sie ihn in Ihr KI-Tool ein.

## Genauigkeit und Verifizierung
- Prompts sind nur Vorlagen. Verifizieren Sie Ergebnisse immer anhand Ihrer Standards und Berechnungen.
- Entfernen Sie vertrauliche Daten, bevor Sie Prompts in externe Systeme einfügen.
- Achten Sie auf konsistente Einheitensysteme beim Ausfüllen der Platzhalter.

## FAQ
- **Läuft es offline?** Ja. Die Prompt-Bibliothek ist eingebettet und läuft vollständig im Browser.
- **Kann ich eigene Prompts hinzufügen?** Noch nicht. Dieser Katalog ist ein festes Starter-Set.
- **Werden meine Daten gespeichert oder hochgeladen?** Nein. Das Kopieren und Herunterladen erfolgt lokal.
- **Warum stehen Platzhalter in Klammern?** Sie sind leicht zu erkennen und vor der Verwendung zu ersetzen.
