## Funktionen
Wählen Sie Prozessanschlüsse, Kammerabmessungen, Entlüftungs- und Entleerungsoptionen sowie Materialien aus und sehen Sie sich eine Live-SVG-Skizze an. Exportieren Sie ein PDF-Datenblatt (datasheet), das die Auswahl für die Beschaffung oder die Überprüfung durch den Lieferanten festhält.

## Wann man es verwendet (und wann nicht)
**Verwenden Sie es, wenn:**
- Sie eine Spezifikation für einen Magnetklappenanzeiger für ein Angebot oder eine interne Prüfung entwerfen.
- Sie Mittenabstände (center-to-center) und Anschlussstandards vor der Bestellung überprüfen möchten.
- Sie ein schnelles Datenblatt-PDF benötigen, um es mit Rohrleitungs- oder Instrumentierungsteams zu teilen.

**Vermeiden Sie es, wenn:**
- Sie zertifizierte Druck- oder Schwimmerberechnungen von einem Hersteller benötigen.
- Sie geführte Radar-Level-Messgeräte (guided wave radar) oder nicht-magnetische Füllstandsinstrumente konfigurieren.

## Eingaben und Ausgaben
### Eingaben
| Eingabe | Beschreibung |
| --- | --- |
| Process connection standard and size | DIN, ANSI, Schweiß- oder Gewindeoptionen für Seitenanschlüsse. |
| Center-to-center dimension | Länge der Messkammer, die zur Skalierung der Skizze verwendet wird. |
| Top and bottom connections | Entlüftungs- und Entleerungsoptionen wie Stopfen, Ventil oder Flansch. |
| Materials and ratings | Kammermaterial, Flanschdruckstufe und Annahmen zur spezifischen Dichte. |
| Instrumentation options | Schalter, Fernübertrager, Heizmäntel und Anzeigeeinstellungen. |
| Project metadata | Tag, Leitungsnummer, Kunde und Notizen für das Datenblatt. |

### Ausgaben
| Ausgabe | Format | Notizen |
| --- | --- | --- |
| PDF datasheet | PDF | Technisches Blatt mit Auswahl und maßstäblicher Skizze. |
| Live SVG preview | SVG | Skizze auf dem Bildschirm, die sich bei Ihren Eingaben aktualisiert. |
| Connection summary | Bildschirm | Prozess-, Entlüftungs- und Entleerungsdetails zur Überprüfung. |

## Bedienungsanleitung
1. Wählen Sie den Prozessanschlussstandard, die Größe und die Druckstufe.
2. Geben Sie die Mittenabstandslänge sowie Details zur Entlüftung und Entleerung ein.
3. Legen Sie Materialien, die spezifische Dichte und optionale Schalter oder Übertrager fest.
4. Fügen Sie Projektmetadaten zur Rückverfolgbarkeit hinzu.
5. Überprüfen Sie die Skizze und exportieren Sie das PDF-Datenblatt.

**Beispiel-Datensatz:** Side connections: DIN DN25 PN40 RF, Mittenabstand: 1800 mm, Oben: 1/2 in NPT plug, Unten: 1/2 in NPT valve, Material: 316L, Optionen: Sensoren oben/unten an, Heizmantel aus, Tag: MLG-101.
- Erwartete Ausgabe: Erzeugt ein PDF-Datenblatt mit den gewählten Anschlüssen, Abmessungen, Materialien und einer Live-Skizze für MLG-101.

## Genauigkeit und Verifizierung
- Die Abmessungen in der Skizze dienen der Veranschaulichung; bestätigen Sie die endgültigen Abmessungen vor der Fertigung mit dem Lieferanten.
- Druck- und Temperaturstufen müssen gegen Ihren Designcode validiert werden.
- Die spezifische Dichte und die Schwimmerdimensionierung sind Annahmen; bestätigen Sie diese bei kritischen Anwendungen mit Prozessdaten.
- Dateien bleiben lokal, bis Sie das PDF herunterladen.

## FAQ
- **Kann ich zwischen metrisch und imperial wechseln?** Ja. Geben Sie die Werte in den Einheiten ein, die Sie verwenden; die Skizze skaliert entsprechend.
- **Ist das PDF für die Einreichung bereit?** Es ist ein vorläufiges Datenblatt; fordern Sie vom Lieferanten eine Bestätigung für zertifizierte Zeichnungen an.
- **Werden meine Tags gespeichert?** Nein. Schließen Sie die Seite, um die Einträge zu löschen, oder speichern Sie das PDF.
- **Kann ich Entlüftungs- und Entleerungstypen anpassen?** Ja. Wählen Sie Stopfen-, Ventil- oder Flanschausführungen.
- **Werden Daten an einen Server gesendet?** Nein. Berechnungen und Export laufen im Browser.
