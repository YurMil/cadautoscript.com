## Funktionen
Ziehen Sie mehrere PDF-Dateien per Drag-and-Drop, ändern Sie die Reihenfolge oder drehen Sie Seiten und exportieren Sie ein sauberes, zusammengeführtes Paket vollständig im Browser. Verwenden Sie es, um Zeichnungssätze aufzuräumen oder Pakete zu überprüfen, ohne Dateien an Cloud-Dienste zu senden.

## Wann man es verwenden sollte (und wann nicht)
**Verwenden Sie es, wenn:**
- Sie die Reihenfolge ändern oder Seiten in einem Zeichnungspaket vor der Freigabe drehen müssen.
- Sie mehrere PDFs zu einem zusammenführen möchten, ohne Desktop-Tools zu installieren.
- Sie die lokale Verarbeitung für vertrauliche Zeichnungen bevorzugen.

**Vermeiden Sie es, wenn:**
- Sie Text bearbeiten, Inhalte schwärzen oder Signaturen anbringen müssen (verwenden Sie PDF Batch Signer für Stempel).
- Ihre Dateien extrem groß sind und besser mit einem speziellen Desktop-PDF-Editor verarbeitet werden.

## FAQ
- **Wird die Qualität komprimiert oder verändert?** Nein, die Ausgabe entspricht den Originalseiten.
- **Können Seiten gelöscht werden?** Neuordnen und Drehen sind die Hauptaktionen; exportieren Sie nur die Seiten, die Sie eingeschlossen haben.
- **Werden Daten hochgeladen?** Nein. Das Zusammenführen erfolgt lokal in Ihrem Browser.
- **Welche Dateigröße kann verarbeitet werden?** Dies hängt vom Arbeitsspeicher Ihres Browsers ab.
- **Kann man hier Dokumente unterschreiben?** Verwenden Sie PDF Batch Signer für Stempel.
