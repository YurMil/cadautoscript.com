## Funktionen
Laden Sie einen Stapel Dateien hoch, sehen Sie sich die neuen Namen mit Regex oder literalem Suchen/Ersetzen an, fügen Sie Präfixe, Suffixe oder Nummerierungen hinzu und laden Sie den umbenannten Satz als ZIP herunter. Alles läuft im Browser ab, sodass Ihre Dateien lokal bleiben.

## Wann man es verwendet (und wann nicht)
**Verwenden Sie es, wenn:**
- Sie Zeichnungsnamen normalisieren oder Jobnummern hinzufügen müssen, bevor Sie ein Paket versenden.
- Sie Nummerierungen oder Präfixe stapelweise ohne Skripte anwenden möchten.
- Sie eine schnelle Offline-Umbenennung mit ZIP-Ausgabe bevorzugen.

**Vermeiden Sie es, wenn:**
- Sie Tausende von Dateien auf der Festplatte umbenennen müssen; verwenden Sie in diesem Fall ein CLI-Skript.
- Sie die Ordnerhierarchie aus verschachtelten Verzeichnissen beibehalten müssen; das Verflachen der Struktur ist hier möglicherweise nicht erwünscht.

| Ausgabe | Format | Hinweise |

## Bedienungsanleitung
1. Ziehen Sie die Dateien zum Umbenennen hinein.
2. Wenden Sie Suchen/Ersetzen, Präfixe, Suffixe oder Nummerierungen an.
3. Überprüfen Sie die Vorschau, um sicherzustellen, dass Namenskollisionen behandelt werden.
4. Laden Sie die ZIP-Datei der umbenannten Dateien herunter.
5. Versenden oder archivieren Sie das umbenannte Paket.

**Beispieldatensatz:** Laden Sie `P-001.pdf`, `P-002.pdf` hoch; suchen Sie nach 'P-' und ersetzen Sie es durch 'FAB-', fügen Sie das Präfix `2025_` hinzu, starten Sie die Nummerierung bei 10.
- Erwartetes Ergebnis: Lädt eine ZIP-Datei mit den Dateien `2025_FAB-10.pdf` und `2025_FAB-11.pdf` herunter.

## Genauigkeit und Verifizierung
- Die Umbenennung erfolgt im Browser; behalten Sie die Originale, bis Sie die ZIP-Datei überprüft haben.
- Regex-Muster sind mächtig – testen Sie sie zuerst an einem kleinen Satz.
- Namenskollisionen werden in der Vorschau behandelt; lösen Sie diese vor dem Export.
- Große Chargen sind durch den Browserspeicher begrenzt; teilen Sie diese bei Bedarf auf.

## FAQ
- **Funktionieren Regex-Muster?** Ja. Verwenden Sie Standard-JavaScript-Regex für fortgeschrittene Umbenennungen.
- **Bleibt die Ordnerstruktur erhalten?** Dateien werden mit neuen Namen in einer flachen ZIP-Datei zusammengefasst.
- **Werden Daten hochgeladen?** Nein. Alles läuft lokal in Ihrem Browser.
- **Wie viele Dateien kann ich gleichzeitig umbenennen?** Das hängt vom Speicher des Browsers ab; teilen Sie sehr große Sätze auf.
- **Was ist mit dem Dateiinhalt?** Die Inhalte bleiben unverändert; nur die Dateinamen werden aktualisiert.
