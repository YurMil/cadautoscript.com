## Funktionen

Ziehen Sie eine Logdatei, die von einem digitalen Druckkalibrator **WIKA CPG1500** exportiert wurde, per Drag-and-Drop in das Tool und erhalten Sie sofort:

- **Geräteidentifikationskarte** — Seriennummer, Modell, Firmware-Version, Kalibrierdaten und Operator-Metadaten, die aus dem Dateikopf gelesen wurden.
- **Messdatentabelle** — eine durchsuchbare und sortierbare Tabelle aller mit Zeitstempel versehenen Druck- und Temperaturmesswerte im Log.
- **Druckdiagramm** — ein interaktives Liniendiagramm der aufgezeichneten Druckkurve über die Zeit.
- **Druckfertiger QC-Bericht** — ein mehrseitiges, für den Druck optimiertes Layout (A4-Hochformat für Tabellen, A4-Querformat für Diagramme), das Sie direkt an einen Drucker senden oder als PDF speichern können.

Alles läuft clientseitig mit React und Material UI. Es verlassen keine Daten den Browser.

## Wann man es verwenden sollte (und wann nicht)

**Verwenden Sie es, wenn:**
- Sie WIKA CPG1500 Kalibrierprotokolle auf einem beliebigen Rechner mit Browser überprüfen müssen.
- Sie eine schnelle visuelle Kontrolle der Druckkurve benötigen, bevor Sie das Zertifikat einreichen.
- Sie einen formatierten QC-Bericht drucken oder als PDF speichern möchten, um ihn an einen Laufzettel oder ein Inspektionspaket anzuhängen.
- Sie Messwerte suchen oder sortieren möchten, ohne die Rohdatei in Excel importieren zu müssen.

**Vermeiden Sie es, wenn:**
- Ihre Logdateien von einem anderen Kalibratormodell stammen (der Parser ist spezifisch für CPG1500).
- Sie eine Stapelverarbeitung von Dutzenden von Logs gleichzeitig benötigen (laden Sie die Dateien nacheinander hoch).

## Bedienungsanleitung

1. **Öffnen Sie das Utility** und klicken Sie auf den Upload-Bereich oder ziehen Sie eine CPG1500-Logdatei per Drag-and-Drop hinein.
2. **Überprüfen Sie die Geräteidentifikationskarte** — bestätigen Sie, dass Seriennummer, Modell und Kalibrierdaten korrekt sind.
3. **Durchsuchen Sie die Messtabelle** — verwenden Sie das Suchfeld, um Zeilen zu filtern, oder klicken Sie auf die Spaltenüberschriften, um zu sortieren.
4. **Prüfen Sie das Druckdiagramm** — bewegen Sie die Maus über Datenpunkte für exakte Werte; zoomen oder verschieben Sie die Ansicht, falls verfügbar.
5. **Bericht drucken** — klicken Sie auf den Drucken-Button des Browsers (`Strg+P` / `Cmd+P`). Das Layout wechselt automatisch zu einem A4-optimierten Bericht mit Seitenumbrüchen für die Identifikationskarte, die Datentabelle und das Diagramm.

### Beispiel-Workflow
Laden Sie eine Logdatei eines kürzlich durchgeführten Drucktests hoch → Überprüfen Sie, ob die Geräteseriennummer mit dem Kalibrierzertifikat übereinstimmt → Überprüfen Sie die Druckkurve auf Anomalien → Drucken Sie den formatierten Bericht aus und heften Sie ihn an den Laufzettel.

## Drucklayout des Berichts

Das Druck-Stylesheet erzeugt einen sauberen, mehrseitigen QC-Bericht:

| Seite | Inhalt | Orientierung |
| :--- | :--- | :--- |
| 1 | Geräteidentität + kompakte Messzusammenfassung | Hochformat (A4) |
| 2+ | Vollständige Messdatentabelle | Hochformat (A4) |
| Diagrammseite | Druckdiagramm mit Legende | Querformat (A4) |

:::tip
Verwenden Sie "Als PDF speichern" im Druckdialog Ihres Browsers, um den Bericht digital neben Ihren Kalibrierzertifikaten zu archivieren.
:::

## Genauigkeit und Datenschutz

- **Nur geparste Daten** — das Tool verändert die ursprüngliche Logdatei nicht; es liest und zeigt die Werte so an, wie sie sind.
- **Keine Uploads** — das gesamte Parsing erfolgt im Browser über clientseitiges JavaScript. Es werden keine Daten an einen Server übertragen.
- **Nur für die Sitzung** — schließen Sie den Tab, und alle geparsten Daten sind weg. Speichern oder drucken Sie Ihren Bericht vor dem Schließen.
- **Gegenquelle prüfen** — gleichen Sie kritische Werte (Seriennummer, Prüfdruck) immer mit der ursprünglichen Logdatei und dem Kalibrierzertifikat ab.

## FAQ

- **Welche Logdateiformate werden unterstützt?** Logdateien, die von digitalen Druckkalibratoren des Typs WIKA CPG1500 exportiert wurden (`.log` / `.txt`).
- **Werden meine Daten auf einen Server hochgeladen?** Nein. Alles bleibt im Browser.
- **Kann ich den Bericht drucken oder speichern?** Ja. Verwenden Sie `Strg+P` / `Cmd+P`, um zu drucken oder als PDF zu speichern. Das Layout ist für A4-Papier optimiert.
- **Funktioniert es offline?** Ja, sobald die Seite geladen ist, wird keine Internetverbindung mehr benötigt.
- **Kann ich mehrere Dateien gleichzeitig analysieren?** Laden Sie die Dateien nacheinander hoch; laden Sie die Seite neu oder löschen Sie die Daten, um ein anderes Log zu analysieren.
- **Was ist, wenn meine Logdatei nicht geparst werden kann?** Der Parser ist spezifisch für das CPG1500-Format. Dateien von anderen Instrumenten werden möglicherweise nicht erkannt. Öffnen Sie ein GitHub-Issue, wenn Sie glauben, dass Ihre CPG1500-Datei funktionieren sollte, es aber nicht tut.
