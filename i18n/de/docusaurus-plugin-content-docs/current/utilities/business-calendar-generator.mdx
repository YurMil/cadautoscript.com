# Business Calendar Generator

![Business Calendar Generator screenshot](/img/og/utilities/business-calendar-generator.webp)

Erstellen Sie einen sauberen jährlichen Geschäftskalender mit regionalen Feiertagen, Unternehmensbranding und exportfertigen Layouts.

<a className="button button--primary" href="/utilities/business-calendar-generator/" data-nobrokenlinkcheck>Dienstprogramm öffnen</a>

## Was es macht
- Erstellt einen Kalender für das gesamte Jahr basierend auf dem ausgewählten Land und Jahr.
- Verfolgt Urlaub, Krankheitstage und benutzerdefinierte Arbeitstage in einem Personalisierungspanel.
- Unterstützt Logo-Uploads und Themen-/Hintergrund-Styling.
- Exportiert druckfertige PDF- oder hochauflösende PNG-Dateien.

## Wann man es benutzt (und wann nicht)
**Benutzen Sie es, wenn:**
- Sie einen feiertagsorientierten Jahreskalender für die Personal- oder Projektplanung benötigen.
- Sie einen sauberen PDF/PNG-Export zum Teilen mit Teams oder Kunden wünschen.
- Sie einen einseitigen Kalender mit Branding und Arbeitszeitkontext benötigen.

**Vermeiden Sie es, wenn:**
- Sie eine Live-Integration mit HR-Systemen oder der Gehaltsabrechnung benötigen.
- Sie Planungsabläufe für mehrere Jahre oder mehrere Standorte benötigen.

## Eingaben und Ausgaben
### Eingaben
| Eingabe | Beschreibung |
| --- | --- |
| Land | Legt den Feiertagsdatensatz für den Kalender fest. |
| Jahr | Generiert den Kalender für das ausgewählte Jahr. |
| Stunden pro Tag | Wird in Personalisierungszusammenfassungen und Tagesanmerkungen verwendet. |
| Personalisierung | Markieren Sie Urlaub, Krankheitstage oder benutzerdefinierte Arbeitstage. |
| Branding | Laden Sie ein Firmenlogo hoch und wählen Sie Themen-/Hintergrundstile. |
| Exporteinstellungen | Wählen Sie Papierformat und PDF-Qualität. |

### Ausgaben
| Ausgabe | Format | Anmerkungen |
| --- | --- | --- |
| Geschäftskalender | Auf dem Bildschirm | Ganzjahresansicht mit Feiertagen und Anmerkungen. |
| PDF-Export | .pdf | Druckfertig, wählbare Qualität. |
| PNG-Export | .png | Hochauflösender Rasterexport. |

## Bedienungsanleitung
1. Wählen Sie ein **Land** und ein **Jahr** im linken Panel aus.
2. Stellen Sie die **Stunden pro Tag** passend zu Ihrem Arbeitsplan ein.
3. Öffnen Sie **Personalisierung**, um Urlaub oder Krankheitstage hinzuzufügen.
4. Laden Sie ein Logo hoch und passen Sie bei Bedarf das Thema/den Hintergrund an.
5. Exportieren Sie als **PDF** oder **PNG** über die Export-Buttons.

**Beispiel:** Generieren Sie einen Kalender für 2026 für Deutschland, fügen Sie Ihr Firmenlogo hinzu, markieren Sie Urlaubswochen und exportieren Sie dann ein A4-PDF für Planungsbesprechungen.

## Genauigkeit und Verifizierung
- Feiertagsdaten sind vorinstalliert; überprüfen Sie diese anhand lokaler Vorschriften oder Unternehmensrichtlinien.
- Exporte werden lokal im Browser generiert.
- Personalisierungsdaten werden im lokalen Speicher gespeichert und können jederzeit gelöscht werden.

## FAQ
- **Läuft es offline?** Ja. Einmal geladen, laufen Generierung und Exporte lokal.
- **Kann ich Personalisierungsdaten importieren oder exportieren?** Das Personalisierungspanel unterstützt Markdown-Import/Export.
- **Wird mein Logo oder meine Daten hochgeladen?** Nein. Dateien und Daten bleiben in Ihrem Browser.
- **Welche Papierformate werden unterstützt?** Formate der A-Serie (A4/A3/A2) mit einstellbarer Qualität.
