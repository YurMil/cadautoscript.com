## Funktionen
Laden Sie CAD-generierte PDFs hoch, erkennen Sie Kopfzeilen und Spalten automatisch, entfernen Sie Revisions- oder Fußzeilen-Rauschen und exportieren Sie CSVs pro Datei oder einen zusammengeführten Master-Bericht. Alles läuft clientseitig, sodass Zeichnungen und extrahierte Daten auf Ihrem Gerät bleiben.

## Wann man es verwendet (und wann nicht)
**Verwenden Sie es, wenn:**
- Sie BOM-Tabellen aus Zeichnungs-PDFs extrahieren möchten, ohne sie manuell neu tippen zu müssen.
- Sie einen schnellen CSV-Export für den Einkauf oder die Qualitätssicherung benötigen.
- Sie lokales Parsing ohne Uploads bevorzugen.

**Vermeiden Sie es, wenn:**
- Ihre PDFs gescannte Bilder sind, die OCR benötigen würden.
- Tabellen stark verbundene Zellen oder variable Spaltenanzahlen haben, die die automatische Erkennung stören.

## Eingaben und Ausgaben
### Eingaben
| Eingabe | Beschreibung |
| --- | --- |
| PDF-Zeichnungen | Vektor-PDFs mit BOM- oder Spezifikationstabellen. |
| Auswahl der Kopfzeile | Bestätigen oder passen Sie an, welche Zeile die Spaltenüberschriften definiert. |
| Automatische Spaltenerkennung | Steuern Sie, wie der Parser Spalten gruppiert. |
| Zeilenfilter | Überspringen Sie Revisions- oder Fußzeilen, die nicht in der CSV erscheinen sollen. |
| Master-Bericht-Option | Kombinieren Sie Ausgaben bei Bedarf in einer einzigen CSV. |

### Ausgaben
| Ausgabe | Format | Hinweise |
| --- | --- | --- |
| CSV pro Datei | CSV | Eine CSV für jede verarbeitete PDF. |
| Master-CSV | CSV | Optionaler kombinierter Bericht über alle hochgeladenen Dateien. |
| Vorschau-Tabelle | Auf dem Bildschirm | Vor dem Herunterladen prüfen und anpassen. |

## Bedienung
1. Laden Sie eine oder mehrere Zeichnungs-PDFs hoch.
2. Bestätigen Sie die erkannte Kopfzeile und passen Sie bei Bedarf die Spalten an.
3. Entfernen Sie Fuß- oder Revisionszeilen.
4. Laden Sie CSVs pro Datei oder einen Master-Bericht herunter.
5. Archivieren Sie die CSVs zusammen mit Ihren Auftragsunterlagen.

**Beispieldatensatz:** Laden Sie zwei Baugruppen-PDFs mit BOM-Tabellen hoch, behalten Sie Kopfzeile 2 bei, entfernen Sie Revisionsnotizen und exportieren Sie sowohl CSVs pro Datei als auch einen master_report.csv.
- Erwartetes Ergebnis: Erzeugt zwei einzelne CSVs plus eine kombinierte Master-Datei mit ausgerichteten Spalten.

## Genauigkeit und Verifizierung
- Basiert auf auswählbarem Text; gescannte PDFs benötigen zuerst OCR.
- Verbundene oder unregelmäßige Tabellen erfordern nach dem Export möglicherweise eine manuelle Bereinigung.
- Überprüfen Sie die Vorschau vor dem Herunterladen, um sicherzustellen, dass die richtige Kopfzeile erkannt wurde.
- Das gesamte Parsing läuft lokal; behalten Sie Ihre eigenen Backups der exportierten CSVs.

## FAQ
- **Unterstützt es OCR für Bilder?** Nein. Es liest nur Vektor-Text.
- **Kann ich viele Dateien gleichzeitig verarbeiten?** Ja. Laden Sie ein Batch hoch und exportieren Sie pro Datei oder als einen Master-Bericht.
- **Werden Daten hochgeladen?** Nein. Alles bleibt im Browser.
- **Wie werden verbundene Zellen gehandhabt?** Der Parser flacht Spalten ab; prüfen Sie dies und passen Sie es nach dem Export bei Bedarf an.
- **Kann ich das Trennzeichen ändern?** Der Export erfolgt als CSV; passen Sie die Trennzeichen später in Ihrem Tabellenkalkulationsprogramm an.
