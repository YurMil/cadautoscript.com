## Funktionen
Berechnen Sie Walzenabstand, Biegezugabe und gestreckte Länge für zylindrische Schalen, bevor das Blech die Walzen berührt. Verwenden Sie Voreinstellungen im Stil von EN 13445 oder ASME VIII, fügen Sie Nahtspalt- oder Überbiegungszugaben hinzu und übergeben Sie die Zusammenfassung dem Bediener.

## Wann man es verwendet (und wann nicht)
**Verwenden Sie es, wenn:**
- Sie Walzenabstand und gestreckte Länge für eine zylindrische Schale benötigen, bevor Sie einen Auftrag an die Werkstatt freigeben.
- Sie die Richtlinien von EN 13445 und ASME VIII vergleichen oder Offsets mit einem Prüfer teilen möchten.
- Sie eine druckbare Setup-Karte für Bediener ohne das Öffnen von Tabellenkalkulationen wünschen.

**Vermeiden Sie es, wenn:**
- Sie Kegel, Übergänge oder nicht-zylindrische Formen walzen.
- Sie Finite-Elemente-Prüfungen oder Berechnungen der Maschinenkapazität über einfache Biegezugaben hinaus benötigen.

## Eingaben und Ausgaben
### Eingaben
| Eingabe | Beschreibung |
| --- | --- |
| Ziel-Schalendurchmesser | Außen- oder Innendurchmesser, den die Schale nach dem Walzen erreichen muss. |
| Blechdicke | Materialdicke, die die neutrale Achse und die Zugabe bestimmt. |
| Schalenlänge und Nahtspalt | Fertige Länge plus etwaige Heft-/Passspalte, die Sie lassen möchten. |
| Standard-Voreinstellung | Wählen Sie EN 13445, ASME VIII oder benutzerdefinierte Zugaben für Ihre Werkstatt. |
| Überbiegung oder Flachauslauf-Zugabe | Wie viel extra Walzen Sie an den Enden wünschen, um Flachstellen zu minimieren. |
| Walzenabstand oder Maschinengeometrie | Optionale Eingaben zur Plausibilitätsprüfung von Kapazität und Durchbiegung. |

### Ausgaben
| Ausgabe | Format | Hinweise |
| --- | --- | --- |
| Walzenabstandsführung | Auf dem Bildschirm | Empfohlener Abstand, um den Zieldurchmesser mit minimalen Flachstellen zu erreichen. |
| Gestreckte Länge | Numerisch | Länge, auf die das Blech vor dem Walzen zugeschnitten werden muss, unter Berücksichtigung des Nahtspalts. |
| Biegezugabe / Abzug | Numerisch | Zugabewerte, die Sie in Ihren Arbeitsplan oder Laufzettel kopieren können. |
| Druckbare Setup-Notizen | Text | Direkt von der Seite kopieren oder drucken für den Walzenbediener. |

## Bedienungsanleitung
1. Geben Sie den Ziel-Schalendurchmesser und die fertige Länge ein.
2. Legen Sie die Blechdicke fest und wählen Sie die Standard-Voreinstellung, die zu Ihrem Auftrag passt.
3. Fügen Sie Nahtspalt und etwaige Überbiegungs- oder Flachauslauf-Anpassungen hinzu.
4. Überprüfen Sie den Walzenabstand, die gestreckte Länge und die Zugabewerte.
5. Drucken oder kopieren Sie die Werte in den Werkstattlaufzettel.

**Beispieldatensatz:** Schalen-AD: 1500 mm, Dicke: 12 mm, Länge: 2500 mm, Nahtspalt: 3 mm, Voreinstellung: EN 13445, Überbiegung: kleiner Endbias zur Reduzierung von Flachstellen.
- Erwartetes Ergebnis: Gibt eine gestreckte Länge, Vorschläge für den Walzenabstand und Zugabewerte aus, die dem Walzenbediener mitgeteilt werden können.

## Genauigkeit und Verifizierung
- Geht von einer zylindrischen Schale mit gleichmäßiger Dicke und moderater Rückfederung aus, die durch die Voreinstellung gehandhabt wird.
- Ersetzt keine Prüfungen der Maschinenkapazität oder detaillierte Spannungsberechnungen.
- Verwenden Sie Werkszeugnisdaten, um die Überbiegung für Legierungen zu verfeinern, die anders zurückfedern.
- Führen Sie eine Stichprobenprüfung an einem Testcoupon durch, bevor Sie Bleche in voller Länge bearbeiten.

## FAQ
- **Unterstützt es sowohl Zoll als auch Metrik?** Ja. Geben Sie Zahlen in dem von Ihnen verwendeten Einheitensystem ein; Berechnungen sind einheitenunabhängig.
- **Kann ich die Ergebnisse exportieren?** Verwenden Sie den Druckdialog Ihres Browsers oder kopieren Sie Werte in Ihre eigene Vorlage; es wird nichts serverseitig gespeichert.
- **Berechnet es Kegel oder Rohrbogen?** Nein. Das aktuelle Modell geht von einem konstanten Zylinder aus.
- **Wie wird die Rückfederung gehandhabt?** Voreinstellungen enthalten typische Toleranzen. Passen Sie Überbiegung oder Zugaben für Ihre Materialcharge an.
- **Werden meine Eingaben gespeichert?** Nein. Schließen Sie die Seite, um alles zu löschen; es bleibt nur im Speicher Ihres Browsers.
