## Versionierung & Telemetrie

- Die meisten eigenständigen Utility-Pakete befinden sich unter `static/utility-apps/*`.
- Gemeinsam genutzte Shell-Assets bleiben unter `static/utilities/*`.
- Aktualisieren Sie das Quellprojekt, aktualisieren Sie das Paket im entsprechenden Verzeichnis und führen Sie dann Commit und Push durch.
- Fügen Sie ein prägnantes Änderungsprotokoll in die Dokumentation ein, wenn ein Rechner oder Makro sein Verhalten ändert.
- Verwenden Sie Browser-Devtools oder benutzerdefinierte Protokollierungsendpunkte, wenn Sie Telemetrie benötigen – standardmäßig wird die Nutzung nicht verfolgt.
