## Funktionen
Öffnen Sie DXF-Dateien im Browser, trimmen oder messen Sie Elemente und speichern Sie Änderungen direkt wieder als DXF, ohne den Umweg über schwere CAD-Software. Ideal für schnelle QS, Makrotests oder Korrekturen, bevor die Geometrie weiterverarbeitet wird.

## Wann man es verwendet (und wann nicht)
**Verwenden Sie es, wenn:**
- Sie überstehende Linien trimmen oder schnelle Messungen vornehmen müssen, ohne Desktop-CAD zu starten.
- Sie CAD-Makros testen und die DXF-Ausgabe verifizieren möchten.
- Sie eine Offline-DXF-Plausibilitätsprüfung wünschen, bevor Sie Dateien an Lieferanten senden.

**Vermeiden Sie es, wenn:**
- Sie 3D-Modellierung, Abhängigkeiten oder fortgeschrittene Konstruktionsfunktionen benötigen.
- Ihre Datei extrem groß oder schraffurintensiv ist und von einer vollwertigen CAD-Workstation profitieren würde.

## Eingaben und Ausgaben
### Eingaben
| Eingabe | Beschreibung |
| --- | --- |
| DXF-Datei | Laden Sie die Zeichnung hoch, die Sie prüfen oder bearbeiten möchten. |
| Layer-Sichtbarkeit oder Farben | Schalten Sie Layer um, um sich auf kritische Geometrie zu konzentrieren. |
| Auswahl- und Fangmodus | Wählen Sie aus, wie Sie Linien auswählen und messen. |
| Einheitenreferenz | Verwenden Sie die Quell-DXF-Einheiten oder Ihre eigene Referenzskala. |

### Ausgaben
| Ausgabe | Format | Hinweise |
| --- | --- | --- |
| Editierte DXF | DXF | Speichern Sie die aktualisierte Geometrie lokal. |
| Messwertanzeigen | Auf dem Bildschirm | Längen und Abstände für schnelle QS. |

## Bedienungsanleitung
1. Laden Sie Ihre DXF-Datei in den Editor.
2. Schalten Sie Layer oder Objektfang um, um die benötigte Geometrie zu isolieren.
3. Trimmen, beschriften oder messen Sie nach Bedarf.
4. Überprüfen Sie die Zeichnung am Bildschirm auf Genauigkeit.
5. Laden Sie die aktualisierte DXF herunter.

**Beispieldatensatz:** Öffnen Sie flange.dxf, trimmen Sie überstehende Konstruktionslinien, messen Sie den Lochkreis und speichern Sie die bereinigte DXF.
- Erwartetes Ergebnis: Gibt eine bereinigte DXF sowie Messwerte am Bildschirm zurück, die Sie in QS-Notizen verwenden können.

## Genauigkeit und Verifizierung
- Entwickelt für DXF-Workflows; erstellen Sie ein Backup des Originals, bevor Sie es überschreiben.
- Große Dateien können sich im Browser langsamer anfühlen als auf einer Workstation.
- Einheiten folgen der Quell-DXF; prüfen Sie den Maßstab beim Import aus Quellen mit unterschiedlichen Einheiten.
- Alle Bearbeitungen bleiben lokal; exportieren Sie, um Ihre Änderungen zu speichern.

## FAQ
- **Welche DXF-Versionen werden unterstützt?** Funktioniert mit gängiger R12+ DXF-Geometrie.
- **Werden Blöcke und Schraffuren unterstützt?** Einfache Blöcke funktionieren; aufwendige Schraffuren können langsamer sein und sollten nach dem Export überprüft werden.
- **Werden Bearbeitungen online gespeichert?** Nein. Dateien verlassen niemals Ihren Browser.
- **Kann ich die Einheiten ändern?** Verwenden Sie die Skalenreferenz in Ihrer DXF; das Tool respektiert die Quellgeometrie.
- **Bleiben die Layernamen erhalten?** Layerdaten bleiben beim erneuten Speichern erhalten.
