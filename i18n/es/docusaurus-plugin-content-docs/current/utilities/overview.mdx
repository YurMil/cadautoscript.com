## Versiones y telemetría

- La mayoría de los paquetes de utilidades independientes viven bajo `static/utility-apps/*`.
- Los activos de shell compartidos permanecen bajo `static/utilities/*`.
- Actualice el proyecto de origen, actualice el paquete en el directorio correspondiente, luego realice commit y push.
- Incluya un registro de cambios (changelog) conciso en los documentos cada vez que una calculadora o macro cambie de comportamiento.
- Utilice las herramientas de desarrollo del navegador o puntos finales de registro personalizados si necesita telemetría; de forma predeterminada no se rastrea nada.

## Incrustar utilidades dentro de los documentos

Consulte [Embedding calculators](./embed-calculators.md) para fragmentos de iframe y envoltorios de React. MDX le permite importar componentes o iframes directamente, para que pueda mantener las instrucciones y la interfaz de usuario juntas.
