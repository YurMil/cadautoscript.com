## Mida see teeb
Kujundage projekti kaustapuu, importige olemasolev JSON või ZIP ning eksportige bash- või PowerShell-skripte, mis taastavad struktuuri. Laadige alla ZIP- või JSON-eelseadistus, et meeskonnakaaslased saaksid luua sama struktuuri ilma käsitsi klikkimiseta.

## Millal seda kasutada (ja millal mitte)
**Kasutage seda, kui:**
- Standardiseerite oma meeskonna jaoks projekti struktuuri.
- Vajate kiiret ZIP-struktuuri ilma CLI-tööriistu käivitamata.
- Soovite jagada kaustade eelseadistust erinevate masinate või meeskondade vahel.

**Vältige seda, kui:**
- Peate seadistama servereid või keerulisi õigusi; see utiliit keskendub ainult kaustapuudele.
- Teie puu sisaldab tuhandeid sõlmi; sel juhul kaaluge koodipõhiste mallide kasutamist.

## Sisendid ja väljundid
### Sisendid
| Sisend | Kirjeldus |
| --- | --- |
| Kausta- ja failisõlmed | Lisage kaustu või faile jooksvalt puu kujundamiseks. |
| JSON või ZIP import | Laadige olemasolev struktuur selle muutmiseks või taaskasutamiseks. |
| Skripti valikud | Valige bash- või PowerShell-eksport sõltuvalt teie keskkonnast. |
| Eelseadistuse metandmed | Valikulised sildid või märkmed struktuuri kohta. |

### Väljundid
| Väljund | Formaat | Märkused |
| --- | --- | --- |
| Bash skript | .sh | Skript puu taastamiseks Unix-laadsetes süsteemides. |
| PowerShell skript | .ps1 | Skript puu taastamiseks Windowsis. |
| ZIP-struktuur | ZIP | Tühjad kaustad/failid pakituna kiireks edastamiseks. |
| JSON eelseadistus | JSON | Taaskasutatav eelseadistus hilisemaks importimiseks. |

## Kuidas kasutada
1. Alustage uut puud või importige olemasolev JSON/ZIP.
2. Lisage kaustu ja faile, kuni struktuur vastab teie projekti mallile.
3. Valige bash või PowerShell eksport (või mõlemad).
4. Laadige alla skript, ZIP või JSON eelseadistus.
5. Käivitage skript turvalises kataloogis struktuuri loomiseks.

**Näide:** Looge struktuur kaustadega src/, docs/, tests/ ja README.md failiga; eksportige PowerShell skript ja ZIP meeskonna jaoks.
- Oodatud tulemus: Pakutakse .ps1 skripti, shell skripti, ZIP-struktuuri ja JSON-eelseadistust, mis esindavad sama puud.

## Täpsus ja kontroll
- Skriptid loovad katalooge nende käivitamisel; kontrollige teid enne täitmist.
- Erimärgid võivad vajada jutumärke erinevates kestades; kohandage neid, kui teie keskkond on range.
- Suured puud on ZIP-i eksportimisel piiratud brauseri mäluga.
- Kogu genereerimine toimub lokaalselt; hoidke eelseadistusi vajadusel versioonihalduses.

## FAQ
- **Kas see muudab minu ketast automaatselt?** Ei. See loob ainult skripte või ZIP-faile; käivitate need seal, kuhu soovite puud.
- **Kas ma saan eelseadistusi jagada?** Jah. Eksportige JSON ja saatke see oma meeskonnale.
- **Kas see töötab võrguühenduseta?** Jah. Kõik toimub brauseris.
- **Kuidas käsitletakse erimärke?** Skriptid tsiteerivad tavalisi märke, kuid kontrollige teid ebatavaliste nimede puhul.
- **Kas ma saan importida olemasolevat puud?** Jah. Importige JSON-ist või ZIP-struktuurist.
